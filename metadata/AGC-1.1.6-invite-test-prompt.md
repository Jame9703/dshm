# DSHM 1.1.6 AGC 邀请测试提示词

版本：`1.1.6 / 1010007`

核心：`0.2.1-rc.3+dshm.96`

## 一、升级前记录

1. 在已安装 `1.1.4` 的手机上记录：
   - 会话数量和最近一条会话标题；
   - 已安装插件列表；
   - 当前工作区路径与至少 3 个文件名；
   - 余额、模型配置等关键设置。
2. 不要卸载旧版，不要清理应用数据，不要删除 `haps/entry/files`。

## 二、安装本轮指定设备测试件

使用 `internaltesting` 指定设备 Profile 签出的单入口 HAP + shared HSP，
不要使用 `app_gallery` AGC APP 直接侧载。

华为官方说明云调试可上传“已配置签名的 debug/release 包”，但没有在云调试文档
中规定 Profile 的具体类型。本项目云调试实测返回 `9568423 device is unauthorized`，
错误明确要求云设备 UDID 出现在签名 Profile 中；当前指定设备 Profile 只包含 4 台
本地测试设备，不含云调试机型。邀请测试则通过 AppGallery 分发，不要求把普通
测试者 UDID 登记到 Profile。

每台设备只提交一个入口：

- PC / 2in1 / MatePad Edge：`pc/`
- 普通平板：`tablet/`
- 手机：`phone/`

必须使用覆盖安装 `install -r`，不得卸载。

## 三、升级后立即检查

1. 旧会话、插件、工作区和关键设置仍在。
2. 首启自动解压 `0.2.1-rc.3+dshm.96`，新会话不报
   `node-addon-system-linux-arm64/bin/musl/system.node` 缺失。
3. 手机数据迁移只新增 `haps/phone/files`，旧 `haps/entry/files` 仍保留。
4. 数据迁移完成后，重启一次，确认不会重复迁移或覆盖新数据。

## 四、PC / 2in1 / Edge

1. 原生终端可启动并执行 `pwd`、`git --version`、`python --version`、`rg --version`。
2. HiShell / PTY 可连续执行命令，窗口缩放后不丢失输入输出。
3. 养鱼插件未预装；可在“设置 → 插件”自行安装。
4. 安装 `dsh-bili-whale` 后运行依赖体检：
   - Node.js：通过；
   - node 运行时：通过；
   - ffmpeg / ffprobe：通过；
   - 数据目录可写：通过。
5. 扫码登录后 `Set-Cookie` 可保存，重开会话仍保持登录。
6. 浏览器任务结束自动关闭；单标签窗口只最小化，不强制销毁。

## 五、普通平板

1. 横竖屏均显示 PC 风格原生顶栏。
2. 左侧栏默认常驻，收起后保留 56px 窄轨。
3. 顶栏侧栏按钮接管 Web 内重复入口。
4. Edge 与 Pro Max 继续走原生终端/PC 路线，不套普通平板分支。
5. 普通平板不会生成 ffmpeg wrapper，也不注入 `FFMPEG/FFPROBE`。
6. 文件夹选择取消后不弹错误；不可用设备落到专属 Download 工作区。

## 六、手机

1. 启动、会话创建、模型调用、插件安装与卸载正常。
2. 左侧栏/右侧栏不重叠；右侧栏打开时左侧入口隐藏，关闭后恢复。
3. 不显示 PC 顶栏，不加载 ffmpeg。
4. 文件选择、工作区浏览、登录回跳正常。
5. 权限只出现手机实际需要的项目，不出现 PC 原生工具专用提示。

## 七、失败反馈

反馈必须附：

- 设备型号、系统版本、设备类型；
- 升级前版本与升级后版本；
- 是否覆盖安装、是否卸载；
- 复现步骤、截图或录屏；
- 发生时间；
- `dshm-host.log` 与迁移 marker（如可导出）。

不要只说“打不开”或“终端坏了”；需要能区分安装、迁移、核心解包、权限、
原生 PTY 和业务接口中的哪一层失败。
