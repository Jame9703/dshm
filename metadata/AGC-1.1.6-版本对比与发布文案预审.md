包体增长来自手机入口 HAP、共享 HSP、独立 Node 运行环境及 PC 端
ffmpeg / ffprobe 动态库闭包。包内仍只有一个 `.96` 核心容器和一份 Python
运行库；ffmpeg / ffprobe 只在 PC `entry`；未内置 `dsh-bili-whale`。

与上一轮同版本 `1.1.6 / 1010007` 候选包（`482,536,262 B`）相比，当前最终包
增加 `24,366,050 B`（`5.050%`）。增量来自本轮补齐的独立 Node 运行环境、
PC 端 ffmpeg / ffprobe 闭包及后续原生终端修复；核心仍为单份 `.96`，没有新增
重复核心或重复 Python 运行库。

## 2. 升级与权限结论

- 1.1.5 PC / 2in1 使用 `entry` 模块，当前版本同模块、同 `filesDir`，覆盖升级
  `1010005 -> 1010007` 不改变已有数据路径。
- 1.1.4 手机从 `haps/entry/files` 升级到 `haps/phone/files`，只复制
  `dsh/home`、`workspace`；旧目录保留，目标已有数据不覆盖，失败可继续补齐。
- 当前 entry 的设备目录、剪贴板、动态沙箱、原生执行和持久文件权限均与
  AGC Profile 已授予的 7 条 ACL 对齐。
- 未加入全盘访问或未审批的新 ACL，APK 文件及相关归档条目均为 0。
- AGC `dshm_three` 为 `release / app_gallery / 0 台设备 / 7 ACL`，与本地
  发布 Profile 逐字节一致。

## 4. 建议替换文案

正式结构化草稿见：

- `metadata/agc-listing-1.1.6-zh-CN.json`

建议一句话简介：

> 本地运行的 AI 编程工作台

建议应用介绍：

> DSHM 是运行在 HarmonyOS 手机、平板与 PC / 2in1 上的本地 AI 编程工作台。
>
> 会话与执行轨迹：完成多轮对话，查看工具调用、执行轨迹与结果。
>
> 本地工作区：授权项目目录后，可浏览、预览和编辑文件；部分设备可使用应用内工作区浏览器。
>
> 内置开发环境：随应用提供终端、Git、ripgrep 与 Python。PC、MatePad Edge 和 MatePad Pro Max 使用系统原生 PTY，手机与普通平板按设备能力使用适配后的终端环境。
>
> 插件与浏览器：支持插件安装、网页抓取和浏览器页面操作；任务结束后可按设置关闭对应页面。
>
> 本地优先：会话、插件和工作区默认保存在设备本地，不设服务端账号体系；模型服务由用户自行配置。
>
> 首次启动需要解压内置核心，可能需要数十秒。

建议更新日志：

> 版本 1.1.6，DSH 端侧核心 0.2.1-rc.3+dshm.96。
>
> 支持设备：手机、平板、鸿蒙 PC / 2in1（含 MatePad Edge / MatePad Pro Max）。
>
> 本次更新：
>
> 1. 【多端支持】统一手机、平板与 PC / 2in1 发布包和核心运行时，改善安装、启动与升级体验。
> 2. 【原生终端】恢复并优化 PC、MatePad Edge、MatePad Pro Max 的系统原生 PTY，提升命令执行、窗口缩放与多任务稳定性。
> 3. 【平板界面】普通平板恢复 PC 风格常驻顶栏与侧边栏，顶部侧栏按钮统一接管重复入口。
> 4. 【插件环境】完善 Node 运行与 JIT 子进程支持；PC 端提供 ffmpeg / ffprobe，移动端按设备能力隔离加载。
> 5. 【开发能力】优化 Python、Git、文件搜索、子智能体工具链、文件工作区与插件安装流程。
> 6. 【稳定性】修复浏览器拉起、登录回跳、任务结束自动关闭、文件桥与侧栏交互问题，并优化 ArkWeb 内存占用。
> 7. 【兼容性】修复手机和平板的工作区选择、终端刷新及布局适配问题。
> 8. 【升级保障】保留已有会话、插件、工作区与关键设置；1.1.4 手机数据和 1.1.5 PC 数据均可无损沿用。
