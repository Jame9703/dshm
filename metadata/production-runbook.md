# 从素材到成片：DSHM 发布片生成手册

> 目标成片：103 秒完整版（`metadata/launch-film-final-script.md`）
> 商店版：从成片裁 45s / 30s
> 前提：素材在 `~/Desktop/上架视频`

---

## 1. 先分清工具分工（关键）

| 环节 | 用什么 | 说明 |
|---|---|---|
| S1/S2/S11 抽象画面、字标动效 | **updream** | 只生成这 3 段，不碰实拍 |
| 实拍拼接、字幕、旁白、音乐、导出 | **剪映专业版 / CapCut**（推荐） | 实拍必须在这里剪 |
| 致谢/关注页排版 | 剪映图文模板 | 二维码用图片层 |
| 二维码裁剪 | 任意截图工具 / 预览 | 裁成方形，≥200px |

**updream 不能自动剪实拍。** 它的产出是「3 段 AI 视频」，剪映的产出是「整条片」。

---

## 2. 八步流程

### 第 1 步：建工程（2 分钟）

剪映 → 开始创作 → 导入任意素材 → 比例 **16:9** → 分辨率 **1080p** → 帧率 **30fps** → 清空演示素材。

### 第 2 步：素材归位（10 分钟）

按脚本 §0 建文件夹：

```
footage/  S3…S10 实拍（重命名，便于找）
ai/       S1 S2 S11（updream 产出）
qr/       6 张裁好的二维码
audio/    voiceover / music
```

同时做三件事：清通知、确认无 token、统一深色。

### 第 3 步：生成 3 段 AI（updream，20 分钟）

用脚本 §5 的提示词生成：

1. S1 代码流（4s）
2. S2 字标 + 三端剪影（4s）
3. S11 收尾排版（6s）

生成后下载到 `ai/`。**字标用官方 `app_icon.png` 叠加，不让 AI 生成中文。**

### 第 4 步：搭时间轴（30 分钟）

按脚本 §1 的时间码，把素材拖到主轨：

```
0–4   S1
4–8   S2
8–18  S3（鸿蒙PC）
18–26 S3 续 / 工作区
26–34 S5 终端
34–40 单形态平板
40–46 双形态平板
46–50 Pura90
50–56 mateX7 / 阔折叠
56–60 三折叠 / MatePad Pro Max
60–66 一碰传
66–70 通知/卡片
70–78 桌宠
78–84 关键词排版
84–90 品牌定版
90–95 致谢
95–103 关注页
```

只求「长度对、顺序对」，不精修。

### 第 5 步：字幕（15 分钟）

剪映 → 文本 → 本地字幕 → 导入 `metadata/subtitles-103s.srt`。

样式：思源黑体 Medium、42–48px、白字 + 20% 黑描边、底部留 15%。

导入后逐条核对是否被播放器控件遮挡。

### 第 6 步：旁白（20 分钟）

- 方式 A：剪映「文本朗读」→ 粘贴脚本 §6 旁白 → 选中性音色 → 生成；
- 方式 B：自己录，按句切分，句间 0.2–0.3s；
- 旁白轨铺好后，用旁白重音微调画面入点。

### 第 7 步：音乐与音效（15 分钟）

剪映 → 音频 → 音乐库（选「商用可授权」标签）→ 按脚本 §8 铺 7 个节点。

- 旁白 -6dB，音乐 -18dB；
- 致谢段音乐降到 -24dB 或留白；
- 音效只留：设备点亮、字标、碰一碰、通知。

### 第 8 步：片尾与导出（20 分钟）

**致谢（90–95s）**：
- 黑底 + 「感谢每一位支持者」；
- 两屏两列，名单见 `metadata/thanks-list-and-endcard.md`；
- 只放名字，不放金额/头像。

**关注页（95–103s）**：
- 2×3 网格，每格「平台名 + 账号名 + 二维码」；
- 二维码裁成方形、≥200px、实测可扫；
- 视频号无二维码，只放「视频号：DSHM开发者」文字。

**导出**：1080p / 30fps / 更高码率 / AAC 48kHz。

## 3. 导出前自检（必看）

- [ ] 总时长 ≈103s，首尾无超 0.5s 黑帧；
- [ ] 三端都出现：PC、平板、手机；
- [ ] 平板竖屏**左上角侧栏按钮**在画面里；
- [ ] 手机状态栏与页面同色，无白条；
- [ ] 二维码**手机对屏能扫**（逐个试）；
- [ ] 账号名与截图一致（彡染二拾一 / Sol / 正经华吹 / Sol5766 / DSHM开发者）；
- [ ] 致谢无金额、无王俊鸿；
- [ ] 无 token / 用户名 / 客户代码；
- [ ] 音乐来自商用曲库，授权截图已存；
- [ ] 首帧可作封面。

---

## 4. 常见问题

| 问题 | 处理 |
|---|---|
| updream 生成时长不准 | 剪映里变速/裁切到目标时长 |
| 字幕与旁白不同步 | 以旁白为准，逐条拖时间码 |
| 二维码扫不出 | 放大到 ≥200px、降低压缩、别加滤镜 |
| 实拍 60fps 卡顿 | 时间线设 30fps，软件自动补帧 |
| 音乐上架被追溯 | 只用剪映「商用」标签或 CC0，保留授权截图 |
| 成片超 103s | 先删桌宠段，再压折叠段，不要压旁白 |
