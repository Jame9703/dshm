# DSHM 华为应用市场上架宣传片脚本（45 秒主版）

> 版本：1.1.8 / 1010020｜核心 `0.2.2-rc.5+dshm.1`
> 用途：华为应用市场「应用视频」+ AGC 邀请测试页 + 官网/社媒复用
> 制作工具：updream（AI 生成 + 实机录屏后期合成）

---

## 一、项目梳理（脚本设计依据）

### 1.1 定位

DSHM 是运行在 **HarmonyOS 手机、平板、PC / 2in1** 上的**本地 AI 编程工作台**。
ArkWeb 只负责渲染界面，真正的会话、工具、插件、终端都在**端侧宿主进程**里执行，代码与上下文默认不出设备。

### 1.2 核心功能（只列可实机演示的）

| 功能 | 演示形态 | 三端 |
|---|---|---|
| 会话与执行轨迹 | 多轮对话 + 每一步工具调用/结果 | 三端 |
| 本地工作区 | 选择项目目录，浏览、预览、编辑文件 | 三端 |
| 内置开发环境 | PC 原生终端（PTY）；平板/手机 guest VM（bash/python/git） | 三端 |
| 插件扩展 | 插件市场安装、启用插件 | 三端 |
| 浏览器自动化 | 按需拉起系统浏览器，任务结束自动收尾 | 三端 |
| 桌面桌宠（dsh-pet） | PC/2in1 桌面悬浮宠物 | PC/2in1 |
| 本地优先 | 会话/插件/工作区存本地；模型凭据用户自配 | 三端 |
| 多端适配 | PC 顶栏三键、平板 280/56 侧栏、手机抽屉 | 三端 |

### 1.3 目标用户

1. **HarmonyOS PC / 2in1 开发者**（主）——需要原生终端与完整工作区；
2. **平板 / 手机移动开发者**——随时随地查看会话、改文件、跑脚本；
3. **对代码隐私敏感的团队/个人**——不接受把源码上传到第三方云端。

### 1.4 差异化（旁白的支点）

- 不是「网页版 AI 聊天」，而是**端侧运行的完整开发环境**；
- 不是「云 IDE」，而是**本地优先**：代码、会话、工作区都在设备里；
- 不是「单端应用」，而是**同一套能力覆盖 PC / 平板 / 手机**。

## 五、updream 制作说明

| 镜头 | 生成方式 | 提示词方向 |
|---|---|---|
| S1 代码流 | AI 生成 | 深色背景，代码符号流动，遇到发光边界折返，极简科技感，无文字 |
| S2 字标/设备 | AI 动效 + 官方 logo | 三台设备剪影依次点亮，克制、无夸张光效 |
| S11 收尾排版 | AI 生成 | 三端并排 + 关键词浮现，深色，稳定构图 |
| S3–S10 | **实机录屏** | 不建议 AI 生成界面（会失真、与真实产品不符） |

原则：**界面一律用实机录屏**，AI 只做抽象背景、字标动效、转场元素。避免 AI 生成的假 UI 与真实产品不一致，导致审核/用户预期偏差。

## 六、素材与音乐合规

### 6.1 可商用（无需额外授权）

- 本项目自行录制的 DSHM 界面、自带插件界面（自有版权）；
- 自制图形、色块、代码流抽象动画（updream 生成，需确认工具条款允许商用）；
- 开源字体：**思源黑体 / Noto Sans SC（SIL OFL）**、**Inter（SIL OFL）**；
- CC0 音乐/音效（如 FreePD、Pixabay CC0 曲目），需保留授权页面截图。

### 6.2 需授权（使用前必须取得书面/平台授权）

- 商业音乐库曲目（Artlist / Epidemic Sound / 华为音乐商用库）——保留订阅与曲目授权编号；
- 华为/HarmonyOS 官方 logo、应用市场标识——按《华为品牌使用规范》，不得暗示官方背书；
- 第三方插件/皮肤的作者界面——需插件作者许可（开源许可证需确认允许宣传使用）；
- 真实用户头像、姓名、聊天内容——需本人书面同意，建议一律用演示数据替代。

### 6.3 禁止

- 未授权的流行歌曲、影视片段、游戏画面；
- 竞品界面截图/logo（避免不正当竞争）；
- 真实 API Key、token、内网地址、客户代码；
- 暗示「华为官方出品」的表述或排版。

### 6.4 音乐建议

- 风格：克制的电子/极简钢琴，60–90 BPM，前 4s 留白突出旁白；
- 结构：S1 低频铺底 → S3 加入节奏 → S8 情绪抬升 → S11 收束留白；
- 混音：旁白 -6 dB 主导，音乐 -18 dB 垫底；字幕安全区底部 15%。
