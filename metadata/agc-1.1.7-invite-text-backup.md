## 更新说明 newFeatures
版本 1.1.7（versionCode 1010008），核心 0.2.1-rc.5+dshm.105
支持设备：6.1.0版本以上手机、平板、鸿蒙 PC / 2in1（含 MatePad Edge / MatePad Pro Max）

更新内容： 
1.【华为账号与云同步】接入华为账号，仅读取账号标识用于同步归属，不保存登录凭据；会话、插件清单与工作区可云端备份并跨设备恢复；插件只同步清单、默认不自动安装；同步内容排除核心运行时与 API Key。 
2.【连接稳定性】修复冷启动偶发提示「连接异常」：系统 Web 内核把本机误判为离线，导致连接循环休眠、不再发起尝试。 
3.【平板界面】侧边栏恢复常驻显示，手动收起后不会被自动拉回。
 4.【登录与通知】登录并入设置分区、不再跳二级页面；Agent 任务完成时在通知栏提示。
 5.【本地模型】PC / 2in1 可直接接入本机模型服务，在设置中填写服务地址即可使用，无需修改代码。 
6.【插件环境】随包提供独立 Node（子进程 JIT）与 PC 端 ffmpeg / ffprobe，在「设置 → 插件」安装养鱼插件后即可使用，无需自行配置。 
7.【稳定性】修复手机首次安装后偶发无法进入应用；修复长时任务在息屏时被系统回收导致的后台连接中断；修复重复入口与登录绕路问题。
 8.【品牌标识】统一替换原有的 dsh 相关标识，应用名称与品牌物料在正式上架前统一完成。

升级保障：推荐安装提前安装dshm-boot-rescue，避免插件引起的核心崩溃，升级安装完整保留会话、插件、工作区、凭据与关键设置，不清理任何用户数据。
