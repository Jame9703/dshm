## 剪映填写提示

1. **大纲**：填 01–17 的短标题，剪映左侧序号可自动生成；
2. **分镜描述**：可拆成多段（剪映支持一个分镜多段描述），每段对应一个画面动作；
3. **已拍摄片段**：点「添加拍摄片段」上传对应 mp4/png；同一分镜用多个素材就加多条；
4. **台词文案**：只填该段旁白；无旁白写「（无旁白）」；
5. **备注**：填时长、转场、字幕与注意事项，方便剪辑时对照。
