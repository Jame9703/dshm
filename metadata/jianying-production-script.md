# DSHM 发布片 · 剪映专用制作脚本（103 秒）

> 素材：`~/Desktop/上架视频`
> 成片：103s（90 正片 + 5 致谢 + 8 关注）
> 适用：剪映专业版（PC）/ 剪映 App（移动端操作同理）

---

## 1. 工程设置

剪映首页 → 开始创作 → 导入任意一个 mp4 进入编辑 → 右上角「修改」：

| 项 | 值 |
|---|---|
| 比例 | 16:9 |
| 分辨率 | 1920×1080 |
| 帧率 | 30fps |
| 背景 | 深灰 `#151517` |

导入后把演示素材从主轨删掉，保留空工程。

## 5. 字幕（T2）

1. 文本 → 本地字幕 → **导入 `metadata/subtitles-103s.srt`**；
2. 全选字幕 → 样式：
   - 字体：思源黑体 / Noto Sans SC Medium；
   - 字号 6–7（约 42–48px）；
   - 颜色白，描边黑 20%；
   - 位置：底部，距下边缘 15%；
3. 逐条检查是否遮挡界面文字。

> 剪映导入 SRT 后，若时间轴有偏移，全选字幕整体拖动对齐。

## 6. 旁白（A1）

剪映「文本」→ 新建文本 → 粘贴下面全文 → 选中文本 → **朗读** → 选「沉稳男声/知性女声」→ 语速 1.0–1.05 → 生成。

```
过去，AI 编程属于一块屏幕。
今天，它属于你手里的每一块屏幕。
DSHM，为 HarmonyOS 而生的本地 AI 编程工作台。
对话、文件、终端，都在设备本地运行。
平板竖屏，侧栏入口一直都在。
横竖之间，布局自己让路。
手机上，接着改。
展开，是一块更大的工作台。
再展开，还是同一套会话。
碰一碰，文件就位。
任务完成，通知直达会话。
桌面，还有一位小助手。
代码默认不出设备，模型由你配置。
DSHM，让 AI 编程，回到你的设备里。
在各平台搜索 DSHM 开发者，获取版本更新与开发日志。
```

生成后删除原文本文本框，只保留音频；把音频按句切开，逐句对齐画面（旁白 -6dB）。

## 7. 音乐与音效（A2/A3）

剪映「音频」→ 音乐库，搜索关键词：

- `科技 极简`、`企业 宣传`、`电子 脉冲`（选带「商用」标识）

按段铺：

| 时间 | 音乐处理 |
|---|---|
| 0–4 | 悬念低频，音量 -20dB |
| 4–18 | 渐入，-18dB |
| 18–60 | 主段，-18dB |
| 60–78 | 轻快，-18dB |
| 78–90 | 收束，-16dB |
| 90–95 | 降到 -24dB |
| 95–103 | 渐弱至 0 |

音效（音效库搜）：

- 设备点亮：`whoosh` / `transition`
- 字标落点：`impact` / `logo`
- 碰一碰：`tap` / `connect`
- 通知：`notification`

每个音效 ≤0.5s，音量 -20dB。

## 8. 片尾

### 8.1 致谢（90–95s）

1. 主轨放纯黑背景（剪映「背景」→ 颜色 `#151517`）；
2. 文本 → 新建文本 → `感谢每一位支持者`（36px，白色 90%）；
3. 再建两个文本框，左列/右列，粘贴名单，行距 1.4；
4. 第一屏 9 人、第二屏 8 人，各 2s，用「动画 → 入场 → 淡入」；
5. 名单见 `metadata/thanks-list-and-endcard.md`，**不含金额、不含王俊鸿**。

### 8.2 关注页（95–103s）

1. 主轨放深色底；
2. 标题 `关注 DSHM 开发者`；
3. 画中画放 6 张二维码，2×3 排列，每格：
   - 平台名（文本，24px）
   - 账号名（文本，20px，70% 白）
   - 二维码（≥200px）
4. 账号名按实际：
   - B站：彡染二拾一
   - 抖音：Sol
   - 公众号：DSHM开发者
   - 小红书：正经华吹
   - 微博：@Sol5766

5. 停留 8s，不加花哨动画，保证可扫。

## 9. 导出

右上角「导出」：

| 项 | 值 |
