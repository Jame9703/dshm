## 一、纯文本版（直接粘贴 AGC）

```
版本 1.1.8 / 1010020，DSH 端侧核心 0.2.2-rc.5+dshm.1。覆盖安装保留既有会话、插件、工作区、凭据与关键设置。

本次更新：
1.【桌面桌宠】PC / 2in1 支持 dsh-pet 桌面桌宠：宠物以小窗显示在桌面上，紧贴本体、可拖动、右键菜单完整；未配置桌面宠物时不会出现任何窗口。需在插件市场安装 dsh-pet，并在桌宠设置中选择「桌面显示」。
2.【启动背景】启动页、启动期状态栏与窗口底色跟随系统深浅色，深色系统下不再出现白闪。
3.【手机状态栏沉浸】手机端启动页与首页的状态栏与页面同色，切换深浅色、重启后保持沉浸。
4.【启动速度】桌面卡片、插件市场等非首屏服务改为在首屏就绪后加载，缩短冷启动等待。
5.【平板/折叠屏】修复单形态平板竖屏时左侧边栏按钮消失（此前仅横屏可见）；折叠屏单屏竖屏同步修复。

首次启动需要解压内置核心，可能需要数十秒；如遇异常，请说明设备型号、系统版本与操作步骤。
```
