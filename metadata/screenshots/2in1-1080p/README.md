# DSHM PC/2in1 AGC 截图

1010005，安装来源 `com.huawei.hmsapp.appgallery`。

截图均为应用独占窗口，不含账号、令牌、真实路径或聊天内容：

| 顺序 | 文件 | 内容 | 分辨率 |
|---|---|---|---|
| 1 | `dshm-2in1-01-home.jpg` | 新建会话与本地工作区主页 | 1920×1080 |

| 3 | `dshm-2in1-03-automation.jpg` | 自动化任务管理 | 1920×1080 |

华为文档页《应用文件要求》列出 PC/2in1 截图 `1920×1280`，但 2026-10-23
Connect API `file-info-update` 实测明确拒绝 `1920×1280`，接受
JPG `1920×1080`。最终交付与 AGC 回读均以 `1920×1080` 为准。
