# DSHM 1.1.7 邀请测试提示词

请按以下顺序验证，并保留截图和相关诊断文件。不要卸载应用，不要清理应用数据。

## 1. 升级数据保留

1. 在已安装 `1.1.5` 或 `1.1.6` 的设备上记录现有会话数、已装插件和工作区。
2. 通过 AppGallery 更新到 `1.1.7`，不要卸载。
3. 打开应用，确认原会话仍可进入、插件仍启用、工作区路径仍可访问。
4. 若是从 `1.1.4` 手机版升级，额外确认旧 `entry` 模块中的会话与工作区已迁移到
   `phone` 模块。回退旧版时旧目录仍应保留。
5. 如出现空列表，请立即采集 `dshm-host.log`、`node-output.log`、`host-crash.log`
   和应用版本截图。

## 2. PC / 2in1、MatePad Edge、Pro Max

1. 打开侧栏终端，确认无需等待 guest VM，能直接出现系统 shell。
2. 执行 `pwd`、`python --version`、`git --version`、`rg --version` 和一条带管道的命令。
3. 新建终端、调整窗口大小，确认没有连续刷新或 PTY 断开。
4. 执行一次 Python 工具和一次文件工作区读写。

## 3. 普通平板

1. 确认横竖屏都有 PC 风格原生顶栏。
2. 确认“DeepSeek Harness”右侧的 Web 侧栏按钮隐藏，只使用顶栏左侧按钮切换侧栏。
3. 确认默认展开、收起后仍保留 56px 左侧窄轨，旋转和切换会话后入口不丢失。
4. 确认 Edge / ProMax 行为与普通平板不同，不要求出现本文的普通平板布局。

## 4. 手机与 API 23–25

1. API 23–25 手机/平板点击“添加工作区”，应出现应用内工作区浏览器。
2. 验证浏览目录、上一级、新建目录、取消和确认。
3. API 26 设备继续验证系统目录选择器与授权跨启动恢复。

## 5. 插件、登录与浏览器

1. 在官方插件页安装一个公开插件，确认 `config/view/preflight` 不长时间卡住。
2. 安装、禁用、更新、卸载后重启应用，确认插件行与依赖状态一致。
3. 完成一次 DeepSeek 账号授权，确认浏览器跳转 `dsh://open` 后应用主窗回到前台。
4. PC 启动一次浏览器自动化任务，确认任务结束后只关闭本会话标签页；单标签页窗口应最小化而不是删除。

## 6. 文件与稳定性

1. 从 Office / PDF / 图片预览进入“文件管理”，确认定位到当前文件。
2. 连续启动 3 次，确认无白屏、无启动崩溃。
3. MatePad Edge 持续运行 10 分钟，记录内存和 CPU，不应再启动 guest VM。
4. 提交反馈时附：设备型号、系统版本、安装来源、升级前版本、复现步骤、截图、
   `dshm-host.log`、`node-output.log`、`host-crash.log`。

## 拒绝判定

- 升级后数据减少且回退后恢复，判定失败。
- PC / Edge / ProMax 终端进入 guest VM 或无法执行系统命令，判定失败。
- 普通平板仍显示重复 Web 侧栏按钮、横竖屏顶栏消失或侧栏入口丢失，判定失败。
- 官方插件页卡死、登录后无法回跳、任务结束浏览器未按约定收尾，判定失败。
