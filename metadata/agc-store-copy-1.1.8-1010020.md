## 3. 应用介绍（项目全貌，约 1100 字，可直接粘贴）

```
DSHM 是运行在 HarmonyOS 手机、平板与 PC / 2in1 上的本地 AI 编程工作台。它不是网页版聊天工具，而是一套在设备内运行的完整开发环境：会话、工具调用、文件读写、终端与插件都在本机执行，代码与上下文默认不出设备。

【核心能力】
1. 会话与执行轨迹：多轮对话，每一步工具调用（读文件、改代码、跑命令）与结果都在轨迹里可见。
2. 本地工作区：通过系统文件选择器授权项目目录，浏览、预览、编辑文件；AI 的读写范围限定在你选择的工作区内，会话恢复或重启后仍可继续。
3. 内置开发环境：终端、Python、Git、ripgrep 随包提供；PC / 2in1 使用系统原生终端，平板与手机使用随包 Linux 环境，无需自行配置。
4. 插件扩展：内置插件与插件市场按需安装，失败可回滚，不影响已有会话。
5. 浏览器自动化：按需拉起系统浏览器完成网页抓取与页面操作，任务结束自动收尾。
6. 桌面桌宠（可选）：PC / 2in1 安装 dsh-pet 并选择「桌面显示」后，可放置透明置顶的桌宠，可拖动、右键菜单完整。

【鸿蒙生态集成】
· 华为账号与云同步（可选）：仅读取账号标识用于同步归属，不保存登录凭据；会话、插件清单与工作区可云端备份、跨设备恢复，排除核心运行时与 API Key。
· 系统通知：Agent 任务完成时按会话分组提示，点击直达会话。
· 服务卡片：PC / 平板可添加用量卡片，状态与真实任务一致。
· 碰一碰：PC 端可接收手机碰一碰传来的文件，只注入、不自动发送。
· 系统托盘与窗口三键：PC 顶栏、最小化 / 最大化 / 关闭跟随系统主题。
· 系统文件选择器与目录授权持久化：授权跨进程重启后自动恢复。
· 深色模式与沉浸光感：跟随系统深浅色；PC / 平板支持系统材质。
· 多形态窗口：自由窗口、分屏、折叠屏单屏 / 多屏、平板横竖屏。
· 长时任务保活：息屏后续期，长任务不中断。
· 系统语音识别：可选语音输入，走系统 Core Speech Kit。
· 应用市场分发：按 HarmonyOS 权限模型最小化声明，适配 AGC 审核与签名体系。

【为跑通鸿蒙做的工程适配】
· 端侧 Node 运行时（jitless）移植，不依赖 JIT / WASM；
· 核心随包安装、升级与回滚，覆盖安装保留数据；
· 启动救援插件、单宿主端口隔离、内存守卫；
· 文件访问栅栏：沙箱与用户目录统一判据；
· 三端壳：PC 顶栏 / 托盘、平板侧栏、手机抽屉、折叠屏形态；
· 启动与沉浸：启动背景跟随深浅色、手机状态栏沉浸、非首屏服务延后加载、平板竖屏侧栏按钮修复。

【适合谁】
· 在 HarmonyOS PC / 2in1 上写代码、需要原生终端的开发者；
· 用平板 / 手机随时查看会话、改文件、跑脚本的移动开发者；
· 不愿把源码上传到第三方云端的团队与个人。

【本地优先】
会话、插件与工作区默认保存在设备本地；应用不设自有账号体系。模型服务由用户自行配置，未配置时仍可查看会话、工作区、插件、终端与设置。

首次启动需要解压内置核心，可能需要数十秒，请耐心等待。
```

## 4. 版本特性（1010020，5 条）

```
版本 1.1.8 / 1010020，DSH 端侧核心 0.2.2-rc.5+dshm.1。覆盖安装保留既有会话、插件、工作区、凭据与关键设置。

本次更新：
1.【桌面桌宠】PC / 2in1 支持 dsh-pet 桌面桌宠：宠物以小窗显示在桌面上，紧贴本体、可拖动、右键菜单完整；未配置桌面宠物时不会出现任何窗口。需在插件市场安装 dsh-pet，并在桌宠设置中选择「桌面显示」。
2.【启动背景】启动页、启动期状态栏与窗口底色跟随系统深浅色，深色系统下不再出现白闪。
3.【手机状态栏沉浸】手机端启动页与首页的状态栏与页面同色，切换深浅色、重启后保持沉浸。
4.【启动速度】桌面卡片、插件市场等非首屏服务改为在首屏就绪后加载，缩短冷启动等待。
5.【平板/折叠屏】修复单形态平板竖屏时左侧边栏按钮消失（此前仅横屏可见）；折叠屏单屏竖屏同步修复。

首次启动需要解压内置核心，可能需要数十秒；如遇异常，请说明设备型号、系统版本与操作步骤。
```

## 7. 权限说明（审核字段，**不**进商店前台）

300 字版（223 字）：

```
PC / 2in1 与平板端申请全盘文件权限，是因为用户选定会话工作区后，需对该目录及全部子目录保持完全控制：读取、搜索、修改、新建、删除、跟随符号链接，并在会话恢复或重启后继续可用。系统只提供单次/单文件授权，覆盖不了整段会话与目录树；全盘权限正是实现该「完全控制」的前提，否则会话内的编辑、Python 与构建工具无法读写文件。该权限仅作用于用户主动选择的工作区，不访问其他目录，不上传文件；手机端不申请该权限，通过系统目录选择器授权工作区。
```
