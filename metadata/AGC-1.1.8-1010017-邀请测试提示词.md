# DSHM 1.1.8（1010017）邀请测试提示词

请按以下顺序验证，并保留截图与相关诊断文件。**不要卸载应用，不要清理应用数据。**

## 0. 安装前记录

1. 记录当前版本号、会话数量、已装插件名单、工作区路径。
2. 通过 AppGallery 邀请测试链接升级到 `1.1.8（1010017）`，不要卸载。
3. 升级后逐项核对上一步记录，确认无缺失。

## 1. 冷启动（本轮重点）

1. 从桌面图标冷启动（先划掉后台任务），记录从点击到界面可操作的大致等待。
2. 连续冷启动 3 次，确认没有白屏、没有「核心无法连接」误报。
3. 若出现长时间等待，请记录：机型、首次还是第 N 次启动、是否刚升级、是否首次启动解包核心。

## 2. 手机 / 平板 guest 终端与 pnpm（本轮重点）

1. 打开终端，执行 `node -v`、`git --version`、`python3 --version`、`tmux -V`。
2. 执行 `pnpm -v`，应在数秒内输出版本号（此前会长时间无响应）。
3. 执行 `pnpm --version`，结果应与上一步一致。
4. 在一个测试工作区执行一次 `pnpm install`（可先用小项目），记录耗时与是否成功。
5. 若 `pnpm` 仍无响应，附 `timeout 120 pnpm -v; echo rc=$?` 的完整输出与机型。

## 3. PC / 2in1 原生终端

1. 打开终端，确认直接出现系统 shell（不进入 guest）。
2. 执行 `pwd`、`git --version`、`rg --version`、`python3 --version` 与一条带管道的命令。
3. 新建终端、调整窗口大小，确认 PTY 不断开。

## 4. 平板侧栏与布局

1. 普通平板：确认只有系统侧边栏入口，没有重复的自绘按钮。
2. 展开 / 收起后入口不丢失；旋转屏幕后布局正常。
3. MatePad Edge / Pro Max 按 PC 形态验证（原生终端 + 常驻侧栏）。

## 5. 插件、登录与浏览器

1. 在插件页安装一个公开插件，确认安装过程不长时间卡住，安装后重启仍在。
2. 禁用、更新、卸载各一次，确认插件行状态与实际生效一致。
3. 完成一次华为账号登录与云同步（可选）：上传后再恢复，确认会话与插件清单正确，插件不会自动重装。
4. PC 启动一次浏览器自动化任务，确认任务结束后只关闭本会话标签页。

## 6. 文件与稳定性

1. 选择/新建工作区，确认可浏览、预览、编辑文件；重启后目录授权仍有效。
2. 从 Office / PDF / 图片预览进入文件管理，确认定位到当前文件。
3. 长时间（≥10 分钟）保持任务运行后切后台再回前台，确认连接与任务状态正常。
4. 提交反馈请附：设备型号、系统版本、升级前版本、复现步骤、截图，以及 `dshm-host.log`、`node-output.log`、`host-crash.log`。

## 拒绝判定（任一项即判失败）

- 升级后会话/插件/工作区减少，且回退旧版后仍无法恢复。
- 手机或平板 `pnpm -v` 仍需数分钟无输出，或 `pnpm install` 无法完成。
- PC / Edge / Pro Max 终端落入 guest，或无法执行系统命令。
- 普通平板出现重复侧栏按钮、入口丢失或布局错乱。
- 冷启动出现白屏、崩溃或长期「核心无法连接」。
