# updream 制作指南：从素材到成片（45 秒）

> 配套脚本：`metadata/updream-edit-script-1.1.8.md`
> 目标：45 秒 / 16:9 / 1080p / 30fps；30 秒版按脚本 §2.1 压缩。
> 原则：**先搭时间轴骨架，再填 AI 段与字幕，最后配音配乐**。不要一上来就精修单镜。

---

## 0. 开工前：素材归位（10 分钟）

建议在电脑上建一个工程目录：

```
DSHM-promo/
├─ footage/          # 实拍录屏
│  ├─ S3_pc_trace.mp4
│  ├─ S4_pc_workspace.mp4
│  ├─ S5_pc_terminal.mp4
│  ├─ S6_pc_plugin.mp4
│  ├─ S7_pc_browser.mp4
│  ├─ S8_tablet_rotate.mp4
│  ├─ S9_phone.mp4
│  └─ S10_pet.mp4        # 无桌宠则不要
├─ ai/               # updream 生成
│  ├─ S1_codeflow.mp4
│  ├─ S2_logo.mp4
│  └─ S11_endcard.mp4
├─ audio/
│  ├─ voiceover.wav
│  └─ music.mp3
└─ subtitles.srt
```

检查三件事：

1. 每段实拍是否 **≥ 脚本要求时长**（S3≥20s、S8≥12s、S9≥12s）；
2. 画面里有没有 **token / 用户名 / 客户代码 / 通知弹窗**，有就先打码或重录；
3. 帧率是否统一（60fps 也能用，时间线设 30fps 即可）。

---

## 1. 新建工程

| 参数 | 值 |
|---|---|
| 画布 | 1920×1080（16:9） |
| 帧率 | 30fps |
| 时长 | 45s（先建 45s，30s 版另存） |
| 背景 | 深灰 `#151517` |

> 如果 updream 只能按素材时长建工程，先建 60s，粗剪后再裁到 45s。

---

## 2. 第一步：搭时间轴骨架（先不精修）

按脚本 §2 的时间码，把素材拖到时间线：

| 时间 | 素材 | 先做什么 |
|---|---|---|
| 0–4 | S1（AI） | 占位，稍后生成 |
| 4–8 | S2（AI） | 占位 |
| 8–14 | S3 | 取「轨迹 running→done」段 |
| 14–18 | S4 | 取「文件树→打开→保存」 |
| 18–22 | S5 | 取「版本输出完整」段 |
| 22–25 | S6 | 取「安装→启用」 |
| 25–28 | S7 | 取「拉起→收尾」 |
| 28–32 | S8 | 横屏→旋转→竖屏按钮 |
| 32–35 | S9 | 抽屉→预览→终端 |
| 35–39 | S10 | 空闲→拖动→菜单（可删） |
| 39–45 | S11（AI） | 占位 |

**先只做「长度对、顺序对」**，画面不完美先不管。这样能立刻看出节奏是否成立。

---

## 3. 第二步：生成 / 替换三段 AI 画面

用脚本 §5 的提示词分别在 updream 生成：

1. **S1 代码流**：深色、代码符号流动、被发光边界拦住，4s；
2. **S2 字标**：DSHM 字标 + 三端剪影，4s（字标用官方 logo 叠加，不要让 AI 生成文字）；
3. **S11 收尾**：三端并排 + 三个关键词 + 字标，6s。

生成后替换时间轴上的占位段。若 updream 生成时长不精确，用变速/裁切对齐到目标时长。

---

## 4. 第三步：字幕（先做，能定节奏）

两种方式：

- **方式 A（推荐）**：把脚本 §3 的字幕时间码做成 `subtitles.srt` 导入；
- **方式 B**：逐条手动加，按 §3 的入/出点。

字幕规范：

- 字体：思源黑体 / Noto Sans SC Medium；
- 字号 42–48px（1080p），白字 + 20% 黑描边；
- 位置：底部安全区 15% 以上；
- 每条 ≤ 18 字，一行放下。

---

## 5. 第四步：旁白

- 用脚本 §4.1 完整版（45s）或 §4.2 精简版（30s）；
- 若用 TTS：选中性偏沉稳音色，语速 1.0–1.05×；
- 若真人配音：按句切分，句间留 0.2–0.3s；
- 旁白轨先铺，再微调画面入出点对齐重音。

---

## 6. 第五步：音乐与音效

按脚本 §6 的节点铺：

| 时间 | 音乐 | 音效 |
|---|---|---|
| 0–4 | 低频 drone | 第 3s 上升 |
| 4–8 | 脉冲加入 | 字标 whoosh |
| 8–22 | 80 BPM 节拍 | 工具完成轻点 |
| 22–28 | 高频点缀 | 安装完成「叮」 |
| 28–35 | 抬升 +2dB | 旋转 whoosh |
| 35–39 | 留白 | 桌宠轻音（可选） |
| 39–45 | 收束长音 | 字标落点 |

混音：旁白 -6dB 主导，音乐 -18dB 垫底；整体 -14 LUFS。

---

## 7. 第六步：转场、调色、细节

1. **转场**：按脚本「转场」列，硬切为主，只在 0→4s、4→8s、39s 用闪白/推近；
2. **调色**：三段 AI 段与实拍统一到深色基调，实拍降饱和 5–10%；
3. **高亮**：光标/点击处加 24px 白色 60% 透明圈；
4. **打码**：路径用户名、token、真实仓库名；
5. **首帧**：0s 即深色 + 字标轮廓，方便商店截封面。

---

## 8. 第七步：导出与自检

导出：H.264 / 1080p / 30fps / 12–16Mbps / AAC 48kHz / -14 LUFS。

自检清单：

- [ ] 总时长 45s（或 30s），首尾无黑帧超 0.5s；
- [ ] 三端都出现：PC、平板、手机；
- [ ] 平板竖屏**左上角侧栏按钮**出现在画面里；
- [ ] 手机状态栏与页面同色，无白条；
- [ ] 字幕不遮挡关键界面文字；
- [ ] 旁白与字幕一致，无错别字；
- [ ] 音乐/音效无版权风险，授权截图已存档；
- [ ] 无真实 token/用户名/客户代码；
- [ ] 无「最强/第一/永久免费」等用语；
- [ ] 首帧可作封面。

---

## 9. 常见坑

| 坑 | 处理 |
|---|---|
| 实拍 60fps 放入 30fps 时间线卡顿 | 先降采样再入时间线，或让软件自动补帧 |
| 录屏有黑边/状态栏 | 裁切到内容区；手机保留状态栏（沉浸是卖点） |
| 字幕被播放器控件挡住 | 底部留 15% 安全区 |
| AI 生成的文字错字 | 字标一律用官方 logo，不让 AI 生成中文 |
| 音乐上架后被追溯 | 只用商用库/CC0，导出前把曲目与授权编号记进交付记录 |
| 时长超 45s | 先删 S10，再压 S3/S8，不要压旁白语速 |
