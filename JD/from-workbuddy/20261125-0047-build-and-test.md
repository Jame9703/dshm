## 4. 验收（重点：启动顺序 + D1）

### 4.1 启动顺序（本轮新增）
1. **首启/升级后第一次启动**，看 `node-output.log`：
   - 期望 `BOOT_50_DSH_INIT` 出现在 `工具链：进程内解包完成` **之前**；
   - 期望出现 `工具链：额外归档 … 延后` 之后才开始解包；
2. 记录从进程启动到 `DSHM_READY` 的耗时，与上一版对比；
3. 首启 3–8 s 内调用 `python3` 可能报「稍后重试」，解包完成后自动恢复——属预期。

### 4.2 Python / D1（关键）
4. `python3 -V` → `3.12.14`；
5. 首次启动后 `$DSHM_SANDBOX_HOME/py-site` 含 `pptx/lxml/PIL/yaml/openpyxl`；
6. **离线**（不联网）执行：
   ```bash
   python3 -c "import pptx, PIL, lxml.etree, yaml, openpyxl; print('preset ok')"
   ```
7. 在线安装一个带 `.so` 的包：
   ```bash
   pip3 install lxml
   python3 -c "import lxml.etree as e; print(e.LXML_VERSION)"
   ```
8. 若第 6/7 步报 `Permission denied`，按 JD-045 §3 取证：
   ```bash
   readelf -S <失败的.so> | grep codesign
   readelf -d <失败的.so>
   ```
   把结果回传，不要只报错误文案。

### 4.3 不影响项（回归确认）
9. 终端可新建、`echo ok`（pty 正常）；
10. `read_image` 正常（sharp）；
11. 平板状态栏沉浸、亮屏不顶窗、Alt+Tab 无空卡片。

### 4.4 手机

13. 若 `python3` 是 exec，再测一次 `pip3 install`；若是桥模式，只要求预设可用。
