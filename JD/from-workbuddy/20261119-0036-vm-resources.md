## 1. 变更摘要

按用户要求，guest VM 资源从"过紧"适度放开：

| 项 | 旧值 | 新值 |
|---|---|---|
| vCPU（`-smp`） | `cpus=1,cores=1` | **`cpus=2,sockets=1,cores=2,threads=1`** |
| guest RAM · 经济档（12G） | 256 MiB | **512 MiB** |
| guest RAM · 性能档（16G+） | 512 MiB | **1024 MiB** |
| TCG buffer · 经济档 | 64 MiB | **128 MiB** |
| TCG buffer · 性能档 | 256 MiB | **512 MiB** |

理由：guest 侧偏紧（pnpm / 安装类命令吃紧）；TCG region 随 vCPU 增长，故 buffer 按 2× 预留（仍远小于 JIT 档历史值 2048）。`VM_MEMORY_MAX_MIB=2048` 未变（1024 仍在上限内）。启动可用内存地板（1280 / 1792）**未改**，避免误拦低内存设备。
