## 1. 构建链与环境（把"能在本机出包"这件事打通）

当天一开始**本机根本出不了包**；下面这条链是一路排掉的真实缺陷，全部已修/已固化。

| 现象 | 根因 | 处置（落点） |
|---|---|---|
| `node` rc=127 `libc++_shared.so` | 沙箱 `bin/node` 包装器走 `node-cli` + el1 `.so`，在本域**不可映射**（dlopen EACCES） | 包装器改为**优先委托 `node-brew`**，失败才回退（`hostcore/app/node-runtime-provision.cjs` + `main.js` 传 `FULL_NODE_PATH`） |
| `npm install` 报 `exit=null` | `tools/pack-core.mjs` 里路径被**无条件加双引号**，POSIX 上 `shell:false` ⇒ spawn 找"带引号的文件名"（`docs/258 §4.1` 的老缺陷**又回到文件里**） | 引号与 `shell` 同进同退 + 把 `r.error` 打进报错 |
| npm 变成"插件安装假壳" | `which('npm')` 命中端侧 shim（`~/bin/npm`） | 在 `Download/<包名>/npm` 放**真 npm 转发**（用 node-brew 跑 DevEco CLT 自带 npm） |
| `place-ffmpeg` 必失败 `Operation not permitted` | brew 的 ffmpeg 与闭包库是 `mode 770`（others 无）⇒ 应用域**读不到** | 新增**显式**复用通道 `--reuse-existing` / `DSHM_FFMPEG_REUSE_ON_UNREADABLE=1`，**必须清单校验完整**（28 个库大小逐条相符）才放行；默认不生效 |
| hvigor 报 `00308002 npm install pnpm failed` | hvigor 按 **Node 可执行文件同目录**解析包管理器；`node-brew` 旁边没有 npm | 同上：npm 转发放在 node-brew 旁 |
| 换 CLT 自带 node 构建 ⇒ 原生崩溃 `rc=133` | CLT node v24.18.1 在本应用域不稳 | 结论固化：**构建统一用 `node-brew`**（v26.12.1），不碰 CLT node |
| `CompileArkTS` 报 `EPERM: scandir '~/data'` | `@ohos/hvigor-arkts-compose` 的 `checkFileWithCase()`（由 `strictMode.caseSensitiveCheck` 驱动）**逐级向上列父目录**，而该目录对本应用不可列 | 本机 `build-profile.json5` 置 `caseSensitiveCheck:false`（**机器绑定且 gitignored**；仓库模板 `tools/build-profile.template.json5` 保持 `true` 未动） |

> 口径：以上都是**本机开发环境**的对策，不是产品运行时行为；产品侧当天只动了 §2 的两处。

⇒ 改成**进程内解析 zip 中央目录**（含 Zip64 兜底）：没有外部依赖，且中央目录的长度字段是权威值。

> 同族的还有两处**未改**（不在今天这条链上，如实登记）：`tools/check-mobile-upgrade-migration.mjs`
> 与 `tools/stage-sideload.mjs` 也用了 `unzip -Z1`；前者在自检里判红（本机跑不动），后者在
> 侧载包流程里。要跑它们时按同一手法换掉即可。

### 10.4 给云调试的两点提醒

1. **发布签名的 APP 不能本地 `hdc install`**（发布 profile 无 UDID ⇒ 覆盖安装会报签名不一致）——
   这正是"给云调试/AGC 上传"的件；本机安装请用 Beta 包（`com.dshm.dshmbeta`，见 §7）。
2. 若云调试要求"设备在 profile 的 UDID 列表里"，本仓另有一条**指定设备**通道：
   `node tools/build-agc.mjs --device-sideload`（用 `.certs/multihap-20261024/`
   的 `…specified-device-20261024.p7b`，含 4 个既有 UDID）⇒ 产出 `…-internaltesting-device-<stamp>.app`，
   可在那些设备上 `hdc install -r` 本地装。
