## 2. 现成框架已具备什么（实读证据）

### 2.1 会话区铺图 —— 已有现成实现

`@iasiv5/dsh-skins/lib/client.js:431-436`：

```js
if (backdrop?.imageLight != null && backdrop?.imageDark != null) {
  lines.push(
    `${scoped} [class*="_centerCol"]{background-image:${backdrop.imageLight};` +
    `background-size:cover;background-position:center;background-repeat:no-repeat}`,
    `${scoped}[data-ds-dark-theme] [class*="_centerCol"]{background-image:${backdrop.imageDark}}`
  );
}
```

**这正是用户要的"会话区放鸿蒙图片"** —— 框架已经写好了，我们只需**提供图片**。

### 2.2 素材如何内嵌 —— base64 WebP

框架把背景图**直接内嵌进 JS**：

```js
backgroundArt: { mime: "image/webp", url: BACKGROUND_ART }
// BACKGROUND_ART = "data:image/webp;base64,UklGRmKYAQBXRUJQ…"
```

实测现有皮肤的内嵌图：

| 项 | 值 |
|---|---|
| 格式 | WebP |
| base64 长度 | 139,408 字符 |
| **解码后体积** | **约 102 KB** |

⇒ **无需外部文件服务，图片直接打进插件包**。这对端侧环境极友好（无网络依赖）。

### 2.3 皮肤 spec 的完整字段（这是我们要填的表）

```js
REQUIRED = [
  "id", "label", "description", "titleBrand", "favicon", "anchor",
  "bodyAttribute",          // 挂到 <body> 的属性名，如 dshHarmonyGlass
  "riding",                 // ★ 令牌覆盖表（颜色都在这里）
  "scrim",                  // 蒙层渐变
  "blur",                   // 模糊强度 { max }
  "glassVar",               // 玻璃变量名
  "desktopBlur",
  "wallpaper",              // ★ 壁纸/背景
  "tints",
  "cssSegments",            // ★ 自定义 CSS 片段（"badge"/"decoration"/"streaming"/"rootclear"/"frost"）
  "Mark", "Name"            // 品牌标记/名称组件
];
OPTIONAL = ["constantTokens", "builtinAssets", "backgroundArt", "decoration", "streaming", "badge"];
```

**关键字段对应关系**：

| 用户需求 | 对应 spec 字段 | 说明 |
|---|---|---|
| 会话区鸿蒙圆图片 | **`backgroundArt`** + `wallpaper` | 现成通路 |
| 侧栏华为元素点缀 | **`cssSegments`**（`decoration`/`badge`）+ `Mark` | 自定义 CSS |
| 沉浸光感配色 | **`riding`**（令牌表） | 覆写 `--dsw-*` 变量 |
| 亮暗双档 | 每个字段都分 `light`/`dark` | 框架原生支持 |

### 2.4 参考实例：现有皮肤怎么填这些字段

`openbmc` 皮肤的真实配置（可直接照抄结构）：

```js
scrim: {
  kind: "baked-gradient",
  stops: {
    light: [["247, 250, 252", 15], ["240, 246, 250", 28]],
    dark:  [["7, 14, 22", 10],    ["4, 9, 14", 24]]
  }
},
blur: { max: 24 },
glassVar: "--dsh-openbmc-glass-blur",
desktopBlur: { dark: "none" },
wallpaper: { kind: "legacy-baked", placeholder: { light: …, dark: … } },
backgroundArt: { mime: "image/webp", url: BACKGROUND_ART },
badge: {
  selector: ".dsh-openbmc-badge",
  colors: { light: { bg: "#14202B", fg: "#F7FAFC" },
            dark:  { bg: "#F7FAFC", fg: "#14202B" } },
  metrics: { lineHeight: "14px", fontWeight: 650 }
},
decoration: { light: "0, 131, 176", dark: "62, 193, 232" }
```

⇒ **结构完全够用**，我们只需换颜色、换图、加华为元素 CSS。

## 3. 素材方案（关键待定项）

### 3.1 素材从哪来 —— 三个选项

| 选项 | 做法 | 优点 | 风险 |
|---|---|---|---|
| **A. 官方设计资源**（推荐） | 从 HarmonyOS 设计规范 SVG/PNG 取出"圆"元素 | 视觉最正、与系统一致 | **本机 `HarmonyOS-KB` 目录存在但无读权限**（见 §3.2） |
| **B. 程序化生成**（最稳） | 用 SVG/CSS 手绘"鸿蒙圆"（同心圆、光晕、渐变球） | **零版权风险、体积小、可无限调参** | 需要设计与调色 |
| C. 第三方素材站 | 下载华为主题站素材 | 现成 | **版权风险高**，商用需授权 |

**⚠️ 我的建议：先走 B（程序化生成）**，理由：

1. **`HarmonyOS-KB` 当前 `Permission denied` 读不到**（实测）；
2. 鸿蒙的视觉语言本身是**几何化**的（同心圆、光晕、渐变球），**用 SVG 精确复现反而比找图更准**；
3. **体积可控** —— 现有皮肤的 102 KB WebP 是照片级素材；纯几何 SVG 可压缩到 **2-5 KB**；
4. **亮暗双档可参数化**（同一份 SVG，换色即可），不必准备两套图。

### 3.2 素材库权限现状（如实记录）

```bash
cd ~/data/HarmonyOS-KB
→ ash: cd: can't cd to …: Permission denied
```

目录**存在**（`ls` 能看到它），但**应用沙箱无读取权限**。
⇒ 选项 A 需要用户**把素材复制到工作区**（`~/data/DSHM-deveco-workspace/`）我才能读取。

### 3.3 「鸿蒙圆」的具体视觉定义（我的理解，待确认）

| 元素 | 形态 | 用途 |
|---|---|---|
| **主圆** | 大半径柔光圆，边缘渐隐（radial-gradient） | 会话区背景主视觉 |
| **同心圆环** | 2-3 层细描边圆环，低透明度 | 增强"系统感" |
| **光晕球** | 高斯模糊的渐变球，可偏移 | 营造景深/沉浸感 |
| **华为元素** | 花瓣/折线/几何切角（建议**抽象化**，避免直接使用商标） | 侧栏点缀 |

> ⚠️ **法律提醒**：**不要直接使用华为商标、花瓣 Logo 等注册图形**。
> 建议走"**神似而非形似**"——用八瓣几何、折角、蓝绿渐变呼应，而不复刻官方标识。
> 这一条请在开工前确认。

## 4. 实施规划（四步）

### 第 1 步：素材生产（不写产品代码）

```text
产出：
  assets/harmony-glass/
    circle-hero.svg     主圆（亮/暗两套配色，参数化）
    ring-set.svg        同心圆环
    glow-orb.svg        光晕球
    sidebar-accent.svg  侧栏华为元素（抽象几何）
  产出物：内联为 data:image/svg+xml;base64 或 <style> 里的 radial-gradient
```

**优先用 CSS 渐变而非图片**（`radial-gradient` 可实现 90% 的"圆"效果，零体积）。

### 第 2 步：皮肤 spec 落地

```js
{
  id: "harmony-glass",
  label: "鸿蒙圆",
  bodyAttribute: "dshHarmonyGlass",
  riding: {
    "--dsw-alias-bg-base":        { light: ["250,250,252", 30], dark: ["14,16,22", 40] },
    "--dsw-specific-sidebar-fill":{ light: ["245,248,255", 45], dark: ["18,20,28", 55] },
    // …按需覆写
  },
  blur: { max: 32 },
  scrim: { kind: "baked-gradient", stops: { light: […], dark: […] } },
  backgroundArt: { mime: "image/svg+xml", url: HARMONY_CIRCLE_URI },
  cssSegments: { decoration: …, badge: … }
}
```

### 第 3 步：验证方式（**这次要一次做对**）

结合 `docs/282/285/288` 的教训，验收必须包含：

| 检查项 | 判据 |
|---|---|
| 皮肤真的挂载了 | `<body>` 上出现 `data-dsh-harmony-glass` |
| 背景图真的铺上 | 会话列 `background-image` 非 `none` |
| **亮暗各测一次** | 两次读数必须不同（`docs/285` 教训） |
| 与玻璃不冲突 | 不写 `background:…!important` 抢列（`docs/286` 教训） |
| 材质挂在浮层 | 列上只放 `background-image`，`backdrop-filter` 挂浮层（`docs/288`） |

### 第 4 步：与 DSHM 的关系

- **DSHM 侧不改任何 ArkTS 代码**（原生已回退，保持现状）；
- 皮肤作为**独立插件包**发布（可进插件市场）；
- 用户可开关，关闭后回到原生外观。

## 5. 现在就能开始的 vs 需要你确认的

### 可以立刻开始（不依赖外部素材）

1. 用 **CSS `radial-gradient`** 画出"鸿蒙圆"背景（零素材、零版权）；
2. 搭出皮肤 spec 骨架并本地验证能挂载；
3. 侧栏点缀用**抽象几何**（八瓣/折角/蓝绿渐变）。

### 需要你确认的 4 件事

| # | 问题 | 为什么必须问 |
|---:|---|---|
| 1 | 素材走 **A 官方库**（需要你把文件拷进工作区）还是 **B 程序化生成**？ | KB 目录我读不到 |
| 2 | 是否接受**抽象化**的华为元素（不复刻商标）？ | 法律风险 |
| 3 | 主色调：**蓝绿**（鸿蒙系统感）/ **蓝紫** / **青蓝**？ | 决定整体观感 |
| 4 | 会话区背景：**纯几何圆**（推荐，轻）还是**照片级图**（重，需 100KB 级素材）？ | 决定素材形态 |
