## 0. 一页结论

| 问题 | 答案 | 依据 |
|---|---|---|
| "沉浸光感"在 API 26 SDK 里对应什么 | **没有单一名为"沉浸光感"的 API**；它是华为系统 UI 的组合效果，公开面 = **`backgroundBlurStyle`（系统级材质模糊）+ `AdaptiveColor`（背景自适应取色）+ `ThemeColorMode.SYSTEM`（跟随系统主题）**，可选 `backgroundEffect`（自定义 radius/saturation/brightness） | SDK 实读（§2） |
| 能否"全 UI 走" | **能，但有结构性边界**：主体界面是 **ArkWeb（Web 组件）**，`web.d.ts` 里**没有** backgroundBlurStyle/Effect 属性 ⇒ **Web 内容本体无法被 ArkUI 特效处理**；能做的是**ArkUI 容器层**（顶栏/侧栏垫片的自绘层、关于面板、会议面板、遮罩、启动页）+ **Web 容器四周的承接层** | §2.3 |
| 能否随系统"沉浸光感强度"设置联动 | **部分能**：`ThemeColorMode.SYSTEM`（明暗）与 `AdaptiveColor.AVERAGE`（背景取色）是**官方公开的系统联动**；但设置里的"沉浸光感强度"滑条是**系统 UI 特效**，**没有公开的读取 API**（`systemConfiguration` 只有 colorMode/fontSizeScale 等配置项，无特效强度字段；`param get persist.ambient.light` 不存在） | §3 |
| 效果定位 | 可达成的最终形态：**系统级材质模糊面板 + 背景自适应取色 + 跟随明暗** —— 视觉上就是"沉浸光感"在应用侧的官方等价物；**强度数值本身拿不到**，只能通过档位（BACKGROUND_THIN/REGULAR/THICK/ULTRA_THICK）映射 | §3 |

**一句话**：效果**可以实现**（ ArkUI 层全量 + 系统联动三件套）；"读系统沉浸光感强度数值"这条**公开 API 不存在**，联动走的是 `ThemeColorMode.SYSTEM` + `AdaptiveColor` 两条官方通道。

## 2. SDK 事实清单（每条都实读）

### 2.1 沉浸光感的公开等价物三件套

| API | since | 语义 | 位置 |
|---|---|---|---|
| `backgroundBlurStyle(value: BlurStyle, options?: BackgroundBlurStyleOptions)` | 9/10 | **系统级材质模糊**；`BlurStyle` 含 `BACKGROUND_THIN/REGULAR/THICK/ULTRA_THICK` 四档（10+） | `component/common.d.ts` |
| `BackgroundBlurStyleOptions { policy?, inactiveColor? }` ← `BlurStyleOptions { colorMode?, adaptiveColor?, scale?, blurOptions? }` | 10/14 | **colorMode=`ThemeColorMode.SYSTEM`（默认）跟随系统明暗**；`adaptiveColor`（`AdaptiveColor.AVERAGE`=取背景平均色做遮罩，10+）；`policy`（`BlurStyleActivePolicy`，14+，前台激活才生效） | 同上 |
| `backgroundEffect(options: BackgroundEffectOptions)` | 11 | 自定义模糊：`radius/saturation/brightness/color/adaptiveColor/policy` 全可调 | 同上 `:17946` |

> `lightUpEffect(degree)`（12+，`common.d.ts:21827`）是**前景提亮**（点击态高光），与"沉浸光感"不是一回事，不采用。
> `setWindowShadowEnabled`（20+）是主窗阴影且要 `SET_WINDOW_TRANSPARENT` 权限，不采用。

### 2.2 系统联动面（官方公开的全部）

- `ThemeColorMode.SYSTEM`（默认值）：**跟随系统深浅色** ⇒ 设置切深色时模糊材质自动换深色版；
- `AdaptiveColor.AVERAGE`：**背景取色** ⇒ 面板后面是什么颜色，遮罩色就趋近什么色（"光感"的精髓）；
- `BlurStyleActivePolicy`（14+）：`ACTIVE`（默认，窗口激活才生效）——**这就是"随激活状态"的官方联动**。

### 2.3 结构性边界（必须先知道）

1. **Web 组件本体不参与**：`web.d.ts` 全文无 backgroundBlurStyle/Effect/haze —— ArkWeb 渲染的是位图合成层，ArkUI 特效属性挂不上它。⇒ "Web 的 UI 全部走"的字面目标**做不到**；
2. 能挂特效的是 **ArkUI 层**：
   - 自绘顶栏（`TopBar()`）、侧栏按钮、菜单；
   - 「关于」/「会议」面板与其遮罩（`Stack` + scrim，现在是 `#4D000000` 实色——**换成 blurStyle 正是首选落点**）；
   - Web 容器**四周的承接层**（如把 Web 装进带 `backgroundBlurStyle` 的 `Column`，视觉上"网页浮在毛玻璃上"——但网页自身内容不模糊）；
3. phone 模块与 entry 同构，同边界。

### 2.4 API 版本可行性

- 工程 `minAPI 6.1.0(23)` / `target 26.0.0`（包内实读 `minAPIVersion=60100023`）；
- 三件套 `@since 9–14` ⇒ **全部在 min 之上，无需版本守卫**。

## 3. "随设置的沉浸光感强度适应"的真相

| 通道 | 有无 | 说明 |
|---|---|---|
| 读"沉浸光感强度"数值 | **无** | `@ohos.app.ability.systemConfiguration`（API 24）只有 colorMode / fontSizeScale / fontWeightScale / language / pointerDevice 等回调，**无任何特效强度字段**；`param get persist.ambient.light` 系统参数不存在；SDK 里 `haze` 仅是系统**图标资源 ID**（`sysResource.js`） |
| 跟随系统明暗 | **有** | `ThemeColorMode.SYSTEM`（默认即跟随） |
| 背景自适应取色 | **有** | `AdaptiveColor.AVERAGE` |
| 激活态联动 | **有** | `BlurStyleActivePolicy`（默认 ACTIVE） |

⇒ **结论**：强度数值拿不到；"系统级调整对接"走官方三条通道，档位用 `BACKGROUND_*` 四档近似表达强度。若要"用户在应用内自选强度"，需要**应用内自建设置项**（映射到四档 + 自定义 radius），这是产品决策不是技术缺口。

## 4. 实现方案（待拍板后执行）

### 4.1 分三步（每步独立可验收）

| 步 | 内容 | 落点 | 验收 |
|---|---|---|---|
| **① 面板层换材质**（低风险高收益） | 「关于」「会议」面板的 scrim 从 `#4D000000` 实色 → `backgroundBlurStyle(BlurStyle.BACKGROUND_THICK, { adaptiveColor: AdaptiveColor.AVERAGE })`；面板本体 `backgroundColor('#FFF0F0F0')` → blurStyle+透明度组合 | `AboutPanel.ets` / `MeetingPanel.ets` | 面板后面内容透出模糊+取色；深浅色自动切换 |
| **② 顶栏与自绘控件** | `TopBar()` 底色 → `BACKGROUND_THIN`（系统顶栏同款材质感）；悬停底色同步 | `WebApp.ets` TopBar | 顶栏"浮"在网页上；网页滚动内容从顶栏下透出模糊 |
| **③ Web 承接层**（可选，视觉激进） | Web 容器外套一层带 `BACKGROUND_THIN` 边框/顶底渐变承接（网页四周毛玻璃化）；**不动 Web 本体** | `WebApp.ets` build() | 网页边缘有光感过渡（内容本身不模糊） |

### 4.2 约束与风险

1. **性能**：`docs/277` 刚修完顿挫——`backgroundBlurStyle` 是 GPU 材质合成，PC/2in1 上成本低，但**手持档低端机**需 `policy: ACTIVE`（默认）+ 真机验收帧率；
2. **门禁连锁**：`check-design-tokens`（新颜色/数值要 token 或 exempt）、`check-brand-surface`（改 AboutPanel 必跑）、`check-decor-button-mode`（顶栏底色与三键配色的接线判据——**改 TopBar 底色会踩这条**，需同步改判据）；
3. **不新增权限**：三件套全是 normal 级 UI 属性，权限面 17/9 不动；
4. **Web 本体不模糊**是硬边界——如果预期是"整个网页毛玻璃"，那是做不到的，先说清。

### 4.3 建议验收口径

```text
① 打开「关于」⇒ 面板后面的网页内容呈模糊+偏色（取背景平均色）
② 系统切深色 ⇒ 面板材质自动切深色版（ThemeColorMode.SYSTEM）
③ 顶栏下网页滚动 ⇒ 内容从顶栏下缘透出模糊层
④ 手持档真机 ⇒ 无掉帧（policy=ACTIVE 时后台不耗）
```
