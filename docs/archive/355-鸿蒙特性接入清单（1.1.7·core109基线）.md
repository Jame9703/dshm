## 3. 观察区（能力存在，但当前不接入）

| 能力 | 不接入的原因 |
|---|---|
| `AppServiceExtensionAbility`（无窗口后台服务） | 需 **ACL** `ohos.permission.SUPPORT_APP_SERVICE_EXTENSION`，仅企业应用可用 |
| `childProcessManager.startNativeChildProcess` | 只能起**原生**入口（`.so` 符号），跑不了 ArkTS 宿主 |
| 应用预加载（完整能力） | 目前只有探针，正式启用需系统侧白名单与功耗评估 |
| 沉浸光感 | 调研见 `docs/279`，与当前 UI 形态冲突，暂不接 |
| 分布式数据（`DISTRIBUTED_DATASYNC`） | 无运行时消费点，已在权限收口中移除（docs/249） |

## 4. 平台封死（**不要再试**）

| 能力 | 证据 |
|---|---|
| 彩色（多色）托盘图标 | `interface StatusBarIcon { white: PixelMap; black: PixelMap }`，注释写 "Pure white / Pure black is recommended"；`updateStatusBarIcon` 同结构 |
| 状态栏自定义视图取代图标 | `StatusBarViewExtensionAbility` 官方定义是"左键点击图标后弹出的**面板**"，不是图标本体 |
| 应用内起第二个 Node 实例 | 原生层"一个进程只允许一个 Node 实例"（`started=false, note=运行时已经启动过`） |
| 手机端原生 execve | 平台拒绝，只能走 guest VM |
| JIT / WASM（主线程） | 无 `ALLOW_WRITABLE_CODE_MEMORY` ⇒ `--jitless`；WASM 仅子进程可用 |
