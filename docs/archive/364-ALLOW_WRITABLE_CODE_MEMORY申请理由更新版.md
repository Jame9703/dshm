## 1. 表单「申请原因」（可直接粘，约 300 字）

```
DSHM 是运行在鸿蒙平板 / PC-2in1 上的本地 AI 编程工作台，应用内嵌 Node.js 24（V8 引擎）
作为本地开发运行时。V8 默认走 JIT：把热点 JS 编译成 ARM64 机器码，写入可写可执行匿名内存
后执行。鸿蒙默认拦截这类内存，未获该权限时主宿主只能以 --jitless 解释模式运行：同一台设备、
同一段计算负载实测 171 ms（JIT）对 1232 ms（解释执行），慢 7.2 倍；且该进程内 WebAssembly
为 undefined，依赖 WASM 的工具与 Node 内置 HTTP 栈只能退回纯 JS 垫片。申请该权限仅用于
让本应用自身进程内 V8 恢复默认工作方式，不加载外部二进制、不动态下发代码、
不采集或上传任何用户数据。手机形态按平台策略不申请该权限。
```

## 2. AGC「权限说明」字段（≤200 字）

```
本应用内置 Node.js（V8）作为本地开发运行时。V8 需要可写可执行匿名内存存放 JIT 编译后的
机器码；无该权限只能解释执行，实测慢 7.2 倍且 WebAssembly 不可用。该权限仅用于本机 JS
执行，不加载外部可执行文件、不下发代码、不采集上传用户数据。
```

## 3. 使用场景（表单「使用场景」+ 附件说明）

1. **本地构建/脚本**：用户在应用内跑 `pnpm install`、TypeScript 编译、打包；这些工具链
   大量使用 JS 热点代码，解释模式下耗时被放大数倍。
2. **插件运行时**：用户从应用内市场安装的 dsh 插件（纯 JS）在本地执行；插件来源可核
   （本机安装记录），不涉及远程下发。
3. **长会话工具调用**：文件读写、终端、检索等工具由内置 Node 运行时驱动，JIT 关闭时
   单轮工具调用延迟明显上升。

## 4. 实测数据（本轮，可复现）

| 负载 | JIT | `--jitless` | 差距 |
|---|---|---|---|
| 2×10⁷ 次 `Math.sqrt` + 位运算 | **171 ms** | **1232 ms** | **慢 7.2×** |
| `typeof WebAssembly` | `object` | **`undefined`** | 功能缺失 |

复现（随包 `nodecli` + 随包签名后的 `libnode.so.137`，与端侧同一份字节）：

```sh
DSHM_NODE_LIBNODE=<app>/hostruntime/libs/arm64-v8a/libnode.so.137 <app>/bin/node \
  -e 'let t=Date.now(),s=0;for(let i=0;i<2e7;i++){s+=Math.sqrt(i)*0.5|0}console.log(Date.now()-t)'
# 加 --jitless 再跑一次
```

## 5. 安全承诺（审核常问，单独成段）

**只做什么**

- 只让 V8 在**本应用自身进程**内申请 W+X 匿名页，用于存放 JIT 机器码与代码缓存；
- 页面随进程退出释放，不落盘、不共享给其它进程。

**不做什么**

- 不加载、不执行任何**外部可执行文件**（ELF/so）；
- 不动态下发、不远程拉取可执行代码；JS 来源 = 随包运行时 + 用户本机安装的工具/插件；
- 不对外提供代码执行服务（本地 HTTP 只绑定 `127.0.0.1`）。

**数据边界**

- 不采集、不上传用户代码、会话内容与凭据；模型凭据仅存本机；
- 该权限不涉及通讯录、位置、相册等任何个人数据权限。

## 6. 边界口径（避免把申请叙事说过头）

| 路径 | 现状 | 与本申请的关系 |
|---|---|---|
| 主宿主（常驻 Node） | 当前 `--jitless` | **本申请要解决的问题** |
| 子进程 Node CLI（工具/插件按需拉起） | 已以 JIT 运行（独立进程） | **不构成本申请论据**；获批后主宿主与它口径一致 |

因此对外只陈述"主宿主进程"的事实：**不要说**"全应用 WebAssembly 不可用"，也不要说
"Node 内置 HTTP 栈完全失效"（主宿主用纯 JS 垫片替代，子进程不受限）。
