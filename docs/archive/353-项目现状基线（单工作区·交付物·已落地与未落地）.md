## 5. 踩过的坑（重复发生过，别再犯）

- **块注释里写 `*/`**（例如 `` `cores/*/node_modules` ``）会提前闭合注释 ⇒ `main.js` 语法错误 ⇒ 进程 SIGABRT 闪退。
  v13–v15 连续三版崩溃的真因就是这个，不是"第二进程"、不是"核心版本"。
- 端侧 busybox **没有** `ls` / `sort` / `awk` / `sed` applet：shell 脚本里禁用它们做命令替换，
  改用 **glob + 内建 test**。
- `bin/dsh` 的核心路径**必须**从脚本自身位置推导（`$0` → `bin/` → 沙箱根 → `dsh/cores`），
  既不能写死版本（.106/.107/.109 连断三次），也不能靠 `SANDBOX_HOME`/`HOME`（真机算出了 `.107`）。
- 端侧 `fs.writeFileSync` **不存在**：用 `openSync + writeSync + closeSync`。
- 覆盖安装**同 `versionCode`** 时系统不刷新应用图标缓存（当前 `versionCode` 1010015）。
- `RunningLock`: `createRunningLock(name, type)` 返回 Promise，ArkTS 编译报错 ⇒ 必须用三参回调重载。
- `module.json5` 的 `process` 必须匹配 `^[:][0-9a-zA-Z_]+$`；UIAbility 必须给
  `startWindowIcon` + `startWindowBackground`；`excludeFromMissions` 标注 "For system application only"（三方语义未定义，不要用）。
