# 398-官方 DSH 的「移动端」口径与我们方案的差异（源码实读）

- 日期：2026-11-07
- 依据：随包核心 `0.2.2-rc.1+dshm.1` 的 `@deepseek-ai/dsh-client-ui-layout`、`dsh-client-ui-sidebar`、`dsh-web-frontend` 实读
- 性质：**只读对照**，不改代码

---

## 1. 官方口径：没有"移动端"，只有"窄视口"

官方布局包里**没有任何 deviceType / 触摸 / 手机判断**，只有两个输入：`window.innerWidth` 和两个 html 属性。

```js
const SIDEBAR_AUTO_COLLAPSE = 1024;
const narrow  = viewport < 1024;                                   // 窄视口
const drawer  = viewport < 768 && !windowsTitlebar;                // 抽屉
const darwin  = document.documentElement.dataset.platform === 'darwin';
const collapsedWidth = drawer || darwin || windowsTitlebar ? 0 : 56;
const sidebarCollapsed = narrow ? !layoutInfo.narrowExpanded : layoutInfo.sidebar === 0;
```

| 视口 | 形态 | 展开 | 收起 |
| --- | --- | --- | --- |
| ≥ 1024 | 三栏 | 280（可拖 264–420） | **56 图标轨** |
| 768–1023（`narrow`） | 三栏 + 窄态记忆 | 280 | **56** |
| < 768（`drawer`） | 抽屉 | 280 覆盖层 + mask | **0（隐藏）** |
| `darwin` / `data-windows-titlebar` | 桌面壳 | 280 | **0**（有自己的标题栏按钮） |

**窄态的"记忆"与重置**（这是平板反复被收起的根源）：

- `narrowExpanded` 默认 **false** → 首次进入 768–1023 就是收起；
- `toggleSidebar` 在 <1024 时只翻转 `narrowExpanded`（不改 `sidebar` 偏好）；
- 重置点：`selectPanel`（仅 <768）、**跨越 1024/768 断点**、`openRightbar`（<1024 且原本未开）。

**抽屉实现**：`sidebarCol` `position:absolute; inset:0 auto 0 0; z-index:71`，收起 `visibility:hidden; transform:translate(-100%)`；
`drawerMask` `z-index:70`，展开时 `opacity:1; pointer-events:auto`（点遮罩 = 关闭）。宽度 `min(sidebar, viewport-48)`。

**唯一的"设备级"适配**：折叠屏半折横向

```js
matchMedia('(device-posture: folded) and (orientation: landscape)')
centeredSidebar = foldedLandscape && viewport >= 768;   // 侧栏宽 = viewport/2，居中
```

**收起态（56 轨）的实际渲染**（`dsh-client-ui-sidebar`）：

```css
.root.collapsed{padding:18px 10px 6px}
.collapsed .logoRow{height:36px;margin-bottom:12px}
.collapsed .iconButton,.collapsed .panelRow{width:36px;height:36px}
.collapsed .toggle .panelIcon{display:none}      /* 默认显示 railMark */
.collapsed .toggle:hover .panelIcon{display:inline}
.collapsed .newSessionLabel{max-width:0}
```

⇒ 官方的"收起"本来就是**一列 36px 图标 + 顶部带 toggle**，不是消失。

**官方在移动端还做了什么**（全部很小）：

- `@media (width<=767px)` 的若干 padding 微调（如列表行右侧让位 48→16）；
- `@media (hover:none)/(pointer:coarse)` 关掉 hover 效果；
- 个别面板用 `100dvh`、`overscroll-behavior:contain`、`visualViewport`；
- **没有** safe-area/状态栏适配、**没有**返回手势/返回栈（SPA 不碰 history）、**没有**设置面板的手机化布局。

## 2. 我们的方案：把"设备形态"当成一等公民

| 维度 | 官方 | 我们 |
| --- | --- | --- |
| 形态来源 | 只有视口宽度 + darwin/windows 属性 | 原生桥 `platformForm()`：`phone/tablet/foldable/desktop`，再分 `dshm-handheld/-tablet/-phone/-desktop/-pc` |
| 平板（tablet） | 落进 `narrow`：默认收起、切面板/开右栏会重置 | **强制常驻**：`grid-template-columns:280px`、`56px` 两档写死；每拍 `ensureTabletExpanded` 补点（800ms→2s→5s 退避）；**用户亲手收起后停手**（isTrusted 意图闩） |
| 平板收起态 | 官方 56 轨（轨内 toggle 显示 railMark） | 仍 56 轨，但**摘掉 `data-sidebar-drawer`**、隐藏 `drawerMask`、侧栏列强制 `position:relative` 回到流内；收起态额外补一颗 ⊞ 并把轨内 opener 让给 ⊞（真机上官方那颗不可见） |
| 手机 / 折叠单屏 | 官方抽屉 + mask | 保留官方抽屉；我们只补 ⊞ 入口、遮罩点击收起、以及抽屉的 z-index/inert 兼容（`clearDrawerInert`） |
| 折叠屏展开 | 官方只是 `narrow`（<1024 时仍收起） | 与平板同款（`dshm-tablet`）：常驻 280、非抽屉 |
| 桌面 / PC | 官方 `sidebar=0` 收起 → 0 宽，靠标题栏按钮 | 桌面档**隐藏官方 toggle**（PC 有自己的原生顶栏按钮），PC 模式收起态用 ⊞ |
| 设置面板 | 桌面式（左 188px 导航） | **直板机**手机化（顶部横向 tab、横向可滚），平板/折叠保持官方 |
| 返回 | 无（SPA 不碰 history） | 能力层 `onBackPressed` + 网页逐级消费（面板二级页 → 右栏 → 浮层 → 抽屉 → 面板首页）+ 近边缘侧滑 |
| 系统层 | 无 | 沉浸式状态栏、`avoidArea`/顶栏避让、窗口装饰与三键、自由窗口/分屏 |

## 3. 差异的代价与结论

**结论**：官方是"桌面 Web 的窄屏降级"，我们是"以设备形态为一等公民的移动端适配"。官方缺的三块正好是我们补的：① 平板常驻（官方 narrow 会反复收起）；② 返回/手势；③ 系统栏与窗口。

**代价**（都是真机上踩过的）：

1. **与官方状态机对抗**：`narrowExpanded` 会在切面板/开右栏/跨断点时被重置，我们只能"补点 + 意图闩"；
2. **抽屉语义冲突**：官方 <768 用 absolute + mask + inert，平板若落进 drawer 就会"点空白收起、遮罩盖住按钮"，必须每拍摘属性；
3. **收起态入口**：官方 56 轨里的 toggle 在真机上不可见（`panelIcon` 默认 `display:none`，只显示 `railMark`），我们只能自绘 ⊞；
4. **两份几何**：一旦我们写死 280/0 而官方 React 仍是 rail 渲染，就会出现"弹一下又缩回去"（docs/385 §2）。

**可执行的三条收敛原则**（供后续改动守）：

- **状态只读官方**（`data-sidebar-collapsed` / `narrowExpanded`），不维护第二套展开态；
- **只覆盖轨道**（`grid-template-columns`），不改列定位（`position/inset/transform`）——除非明确要"去抽屉"；
- **入口只留一颗**：同一列里官方 toggle 与我们的 ⊞ 二选一。

## 4. 附：官方断点常量速查

| 常量 | 值 | 含义 |
| --- | --- | --- |
| `SIDEBAR_AUTO_COLLAPSE` | 1024 | 窄态阈值（默认收起） |
| 抽屉阈值 | 768 | `<768 && !windowsTitlebar` |
| `collapsedWidth` | 56 / 0 | 非抽屉 56；抽屉或 darwin/windows 0 |
| 展开宽度 | `clamp(sidebar, 264, 420)`，默认 280 | 可拖拽记忆 |
| 右栏 | `clamp(rightbar, 300, viewport*ratio)` | `available < 300` 时不显示 |
| 折叠半折 | `centeredSidebar` | 侧栏 = viewport/2（仅 folded + landscape + ≥768） |
