### 1.1 「云盘失败」的真实身份

`12:43:25` 的两条报错来自 **`cloudStorage.bucket()`** —— 即 `HuaweiCloudProbe`
诊断页第②步「云盘连通（真实 list）」的调用。

关键结论：

| 事实 | 依据 |
|---|---|
| 这是**开发者云存储**（CloudStorage），不是端云同步 | `CloudDevelopProxyStorage: GetDefaultBucket` 是 cloudStorage 模块的内部实现 |
| 它需要 AGC 建存储实例（bucket），我们**从未建也决定不建** | docs/304 决策：改走 Asset 端云同步 |
| 所以这个失败是**预期行为**，**不是故障** | bucket 不存在 ⇒ `GetDefaultBucket result error` 必然发生 |
| **Asset 端云同步本身没有报错** | 12:43:28-29 的 DSHM.db 打开 + IsValid enable:1 全部正常 |

> ⚠️ 也就是说：**同步没坏，坏的是诊断页的语义**——它用一个已放弃路线的
> 必然失败冒充"同步故障"，让用户误以为功能有问题。

## 2. 重构内容

### 2.1 顶栏菜单：直接登录入口（`WebApp.cloudMenu`）

**重构前**：

```text
云同步 ▾
├── 未登录华为账号      ← 置灰状态行，点不了
└── 云同步设置…         ← 要再进设置页找登录按钮
```

**重构后**：

```text
云同步 ▾                        云同步 ▾
├── 登录华为账号…  ← 可点！      ├── 已登录 ****abcd  ← 状态行
└── 云同步设置…                  └── 云同步设置…
     （未登录时）                     （已登录时）
```

### 2.2 登录路径单一化（关键设计）

菜单「登录华为账号…」**不新写登录逻辑**，路径是：

```text
菜单点击 → SyncEngine.requestLogin() → WebApp 收到 'login' 事件
  → cloudSyncOpen=true + cloudSyncAutoLogin=true
  → CloudSyncSettings.aboutToAppear 消费 autoLogin
  → showLoginPanel=true（官方 LoginPanel 拉起）
  → 消费即清零（一次性）
```

三条纪律：

| 纪律 | 理由 |
|---|---|
| LoginPanel 仍只在 `CloudSyncSettings` 里 | SDK 逐字：`LoginPanel can be used only on pages, not on dialog boxes`；登录控制器/错误码翻译只有一份，不复制 |
| `autoLogin` 是**一次性信号** | 若常驻为真，用户以后每次主动打开设置页（只想看开关）都会被强弹登录 |
| 登录成功后菜单自动变状态行 | `cloudMenu()` 每次展开重新求值 `SyncEngine.state()` |

### 2.3 SyncEngine 事件通道合并

原来三个语义分散的 setter（`onDiagnostics` + 两个 open）合并为：

```ts
export type SyncUiListener = (which: 'login' | 'connect' | 'asset') => void;
SyncEngine.onUi(listener);   // 宿主注册一次
SyncEngine.requestLogin();   // 'login'
SyncEngine.openDiagnostics(); // 'connect'
SyncEngine.openAssetDiagnostics(); // 'asset'
```

同时删掉了状态快照里两个从未被读的字段（`diagnosticsOpen` / `assetDiagnosticsOpen`）。

### 2.4 诊断分组语义修正（`CloudSyncSettings`）

**修正前**（误导）：

```text
诊断
├── 连接诊断      检查账号与云端连接是否正常（测试用）   ← 会显示红叉，像故障
└── 资产同步诊断  Asset 资产同步自检（测试用）
```

**修正后**（如实）：

```text
诊断
├── 连接诊断（旧路线）      华为账号登录与 Kit 能力检查可用；云盘一段走未启用的
│                          开发者云存储，预期显示失败——当前同步走下方资产通道
└── 资产同步诊断（现行路线） 端云同步（Asset 资产）自检——docs/307 采用的正式通道
```

`HuaweiCloudProbe` 面板页头也加了一行同样的说明（②云盘连通预期失败）。
