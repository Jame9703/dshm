## 提示词正文（从下一行开始复制）

```text
【DSHM Beta 1.1.4 复测任务 · 重点 MatePad Edge 内存问题】

一、本轮目标（按优先级）

P0：确认 MatePad Edge（QXS-W20，HarmonyOS 7.0，24GB+50GB swap）启动后不再"炸内存"
    ——上一版是启动约 78 秒触发系统 PSI，随后 97 条杀进程/换页记录，最后设备重启。
P1：其他设备做一次 5 分钟快速回归，确认没有变慢/变卡/新闪退。
P2：上一轮 10 项冒烟里没测完的项照常补测（见第四节）。

二、测试包与安装

1. 包名：com.dshm.dshmbeta（和 AGC 邀测包 com.dshm.dshclient 是两个包，可共存）
2. 文件：DSHM-beta-1.1.4-core0.2.1-rc.2+dshm.78-arm64-signed.hap
   大小 439,477,521 B
   SHA256 2ADDAFC4EF278A4BA5376F35F25DFAB210C9E8B578C52D1A097E43BD50F6D12E
   （装前请核对；不一致就不要装，直接报"包不对"）
3. 安装：覆盖安装，绝对不要卸载！
   - 有 hdc：hdc install -r <hap 路径>
   - 无 hdc：把 hap 放到设备"下载"目录，用文件管理器点开安装；弹出"是否替换"选替换
4. 装完先不要启动，等我们确认（如果没人确认，就按第三节开始）。

三、MatePad Edge 内存专项（P0，约 5 分钟）

准备：
- 设备电量 > 40%，接电源；
- 关掉不用的后台应用（微信/QQ/抖音等可留着，但记下开了哪些）；
- 屏幕亮度固定，不要自动锁屏；
- 如果能录屏，从启动前就开始录。

步骤（请严格按顺序，记录时间点）：
1. 记下当前时间（精确到分钟），从桌面启动 DSHM Beta；
2. 进入应用后，正常停在主界面，不要操作，保持前台 3 分钟；
3. 3 分钟后再打开"设置"→"关于版本"，停留 30 秒；
   12G 设备日志应为 `economy / guest=256 / tcg=64`；16G 及以上设备应为
   `performance / guest=512 / tcg=256`，60 秒后允许静默预热；
4. 切到平板全屏模式，再打开右侧栏终端：应仍按 PC 桌面布局运行，终端应走系统原生终端；
   日志里不应出现 `终端接管请求` / `端侧 VM 不可用`；
5. 回到会话界面，新建一个会话，发一句"你好"，等回复；
6. 切到后台 30 秒，再切回前台；
7. 从多任务划掉 DSHM Beta，重新打开一次；
8. 全程观察：有没有卡死、闪退、设备发烫明显、其他应用被系统杀掉、桌面卡顿。

通过标准（必须全部满足）：
- 启动后 3 分钟内，应用不闪退、不卡死；
- 设备没有出现"正在清理内存/其他应用被杀"的现象（微信/QQ 不应被杀）；
- 切后台再回来，界面正常、会话还在；
- 划掉后能正常重新打开，不卡在启动页。

如果复现（出现卡死/闪退/大量应用被杀/设备重启）：
- 立即停止操作，记下精确时间（时:分）；
- 不要重启应用反复试，不要清数据；
- 把时间点、当时在做什么、录屏（如果有）发我们，研发按时间点取日志。

四、10 项冒烟清单（P2，其他设备也请一起做）

每项记"通过/失败/阻塞"，失败附现象：
1. 新建会话 → 发一句话 → 收到回复；
2. 听写：点输入框麦克风，允许权限，连续说 20 秒中文，看文字是否进输入框；
3. 侧栏与返回：打开/收起左侧栏；打开右侧栏（文件/终端）→ 返回手势应先关右侧栏，再返回才退桌面；
4. 插件安装：插件市场安装一个小插件，安装期间界面应保持可点；
5. 长命令：让 Agent 跑一段 20 秒以上的 Python 或命令（若报"python 不可用"，按"已知阻塞"记录，不算新缺陷）；
6. 切后台 30 秒再回前台，会话与输入内容应还在；
7. 2in1/平板：自由窗口四边/四角都能缩放；最大化↔自由窗口切换后侧栏入口仍在；
8. 分屏 + 旋转屏幕，内容不空白、不偏移；
9. 深浅色切换，顶栏/侧栏/输入区配色正常；
10. 划掉重开 ×3，每次左侧栏都应直接出现（不需要点右上角按钮）。

五、证据采集（能采就采，采不到就只报时间点）

1. 应用内诊断文件（覆盖安装后位置不变）：
   hdc shell "cat /data/app/el2/100/base/com.dshm.dshmbeta/haps/entry/files/diag-mem"
   把前 20 行发我们（里面应有 web-render-mode=single 和每 10 秒一行 rss/avail）。
2. 系统故障记录：
   hdc shell "hidumper -e --list"
   只要出现 OPsiHandlerInner / LowMemoryKill / OomKiller / SwapFull 的行，连时间一起发。
3. 应用日志（可选，研发也能取）：
   hdc file recv /data/app/el2/100/base/com.dshm.dshmbeta/haps/entry/files/dshm-host.log
   hdc file recv /data/app/el2/100/base/com.dshm.dshmbeta/haps/entry/files/node-output.log
4. 如果设备已经卡到无法执行命令：直接录屏 + 记住时间点，重启后把时间点给我们。

六、反馈模板（每条问题复制这段填）

- 设备型号/系统版本：
- 设备形态（手机/平板/2in1，是否电脑模式/分屏）：
- 包名与版本（设置→关于版本里看）：
- 问题发生时间（时:分，精确到分钟）：
- 当时在做什么（第几步）：
- 现象（卡死/闪退/被系统杀/设备重启/其他）：
- 能否稳定复现（几次里几次）：
- 附件（录屏/截图/诊断文件）：
- 是否伴随其他应用被杀（列出名字）：

七、已知阻塞项（不要当新缺陷报）

以下现象上一轮已定位为"该机型平台限制/已知问题"，本轮只要确认现象一致即可：
1. MatePad Edge 上 Python 桥报 "python 桥拒绝执行：python lib load already failed"
   （伴随 sandbox-dlopen/pty-spawn/exec 被拒）——已知平台限制，研发另案处理；
2. 插件安装/长命令提示 bash/ash/rg/python3.12 "EPERM"、git 缺失——同上；
3. 首次启动解包工具链较慢（约 10-20 秒）——正常；
4. 平板自由窗口下系统标题栏三键不显示（部分机型系统限制）——正常。

八、时间与回传

- 目标完成时间：收到本提示后 24 小时内回传一轮；
- 回传方式：直接在本群发"复测结果 + 第六节模板"，附件命名用"设备名-时间点-现象"；
- 如果 P0 通过、P1/P2 全过，也请回一句"MatePad Edge 3 分钟无 PSI，其他设备通过"，
  我们需要这句话来关闭本轮。
```
