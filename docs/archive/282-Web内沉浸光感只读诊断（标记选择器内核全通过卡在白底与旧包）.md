## 8. G. 判断

### 8.1 三项假设全部排除

| 假设 | 判定 | 依据 |
|---|---|---|
| ① 没挂上标记 | **✗ 排除** | `htmlClass="dshm-desktop dshm-glass-top"`、`glassTop=13` |
| ② 挂了但选择器没命中 | **✗ 排除** | `cols=1`；`diag2 matches=true styleEl=yes hasRule=true` |
| ③ 命中了但 `backdrop-filter` 不被支持 | **✗ 排除** | `cssSupports=yes`；computed 值 `blur(40px) saturate(1.5)` ≠ `none` |

**⇒ 正确答案在三个选项之外：`④ 命中了、也支持，但视觉上不可辨。`**

### 8.2 原因一：半透明白叠在白画布上 = 视觉零变化

| 环节 | 值 | 出处 |
|---|---|---|
| 我们给的底色 | `rgba(249, 250, 251, 0.72)` | 运行时 computed |
| 官方中间列底色 | `background: var(--dsw-alias-bg-base)` | `dsh-client-ui-layout/lib/client.js` `_centerCol` 规则 |
| 该 token 解析 | `--dsw-alias-bg-base` → `--dsw-static-neutral-bluish-00` | `dsh-client-ui-theme/lib/client.js` |
| `249,250,251` 对应 | `#f9fafb` = `--dsw-static-neutral-bluish-50/60` | 同上 |

**白 72% 叠在背后同样白 ⇒ 仍是白**；`backdrop-filter` 模糊的也是白 ⇒ **取色与模糊都作用在同一片白上，
增量为零**。这不是实现错误，是「白底 + 白色系材质」的物理必然。

### 9.1 关于「第 2 条能不能根治」的一句实话

即使打出 180% 的包，**亮色主题下的观感增量仍然有限**：`rgba(226,232,244,0.82)` 是淡蓝灰，
背后是纯白，`blur` 对白底不产生可辨纹理。**真正能看出「玻璃」的场景只有两个**：

1. **深色主题**（暗底 + 白底内容，反差足）；
2. **列内有可滚动的彩色内容**从材质下方经过（模糊才有对象）。

若产品要求「亮色下也要明显」，只能加大不透明度或改用带色材质——
但那会滑向 `docs/196` 的**染蓝**风险。**建议优先在深色主题下验收**，亮色只求「不脏」。
