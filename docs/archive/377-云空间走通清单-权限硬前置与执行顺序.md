## 0. ⚠️ 更正：**不需要 `DISTRIBUTED_DATASYNC`**（本文初稿判错了）

**用户反馈"ACL 列表里找不到这个权限"是对的** —— 因为它对**端云同步**本来就不是必需项。两条官方证据对照：

| 指南 | 是否要求该权限 |
|---|---|
| `同应用跨设备数据同步（分布式）/关系型数据库跨设备数据同步 (ArkTS).md:122` | **要求**：「需要申请 `ohos.permission.DISTRIBUTED_DATASYNC` 权限」 |
| `同应用端云数据同步（分布式）/端云数据同步关系型数据库端侧开发指导 (ArkTS).md` | **全文没有任何权限要求**（`grep 权限\|permission` = 0 命中） |

⇒ `DISTRIBUTED_DATASYNC` 是 **`DistributedType.DISTRIBUTED_DEVICE`（跨设备）** 的权限；我们用的是 **`DISTRIBUTED_CLOUD`（端云）**，走的是**华为账号 + 系统「云空间」开关 + 会员**这条授权链，**不需要声明任何新权限**。

本文初稿引用的 `Interface (RdbStore).md` 里那行「需要权限」标注，是打在**通用重载**上的（覆盖设备场景），我按它下结论是错的。**§1 的"权限面 17→18"整节作废，不必改 `module.json5`、不必重签 Profile、不必提 ACL 申请。**

### 那 `CLOUD_DISABLED schedule=2` 到底是什么

不是权限问题，按可能性排序：

1. **用户没在系统「设置 → 云空间」里打开本应用的同步开关**（官方明确指出这是用户侧前置）；
2. **云空间版本 < 6.3.0 / 系统 < 6.1.0**，或不在中国大陆；
3. **AGC 云空间容器/数据类型/字段与本地不一致**（容器必须是 `DSHM`、「**本地表名称**」必须填 `sync_units`、12 字段逐字一致；「数据类型名称」用合法字母数字（如 `dshmsyncunits`，因下划线会被 AGC 拒收））；
4. 未登录华为账号（端云同步以账号为同步主体）。

## 2. AGC 云空间配置（照 `docs/374` §2，但字段补到 12 个）

| 项 | 值 |
|---|---|
| 容器 | **`DSHM`**（= 本地库 `DSHM.db` 去后缀） |
| 数据类型名称 | **`dshmsyncunits`**（或任意合法字母数字；`sync_units` 因下划线被 AGC 拒绝） |
| **本地表名称** | **`sync_units`**（= 端侧 `SYNC_TABLE`，逐字一致；表单里的独立字段） |

| 字段 | 云侧类型 | 本地类型 | 备注 |
|---|---|---|---|
| `unit_id` | String | TEXT PRIMARY KEY | **高级设置 → 端侧去重主键** 必须勾 |
| `kind` | String | TEXT | 会话/附件/技能/插件清单 |
| `workspace_id` | String | TEXT | ⚠️ 不是 `workspace` |
| `session_id` | String | TEXT | 合并去重的键 |
| `version` | Integer | INTEGER | |
| `sha256` | String | TEXT | |
| `bytes` | Integer | INTEGER | |
| `updated_at` | Integer | INTEGER | 内容修改时间 |
| `metadata` | String | TEXT | |
| `payload` | **Asset** | ASSET | 官方映射 `Asset↔ASSET`；控制台有 Asset 时不要选 Bytes |
| **`device_id`** | String | TEXT | **新增**（本地已加列） |
| **`uploaded_at`** | Integer | INTEGER | **新增**（本地已加列） |

> **⚠️ 毫秒时间戳不能用 `Integer`**：AGC 的 `Integer` 是 32 位（上限 2,147,483,647），
> 而 `Date.now()` 是 13 位（≈1.7×10¹²）**必溢出**。所以 `updated_at` / `uploaded_at`：
> ① 有 **Long** 就选 Long；② 没有 Long 就选 **`Date`**（官方示例里就有，语义最正）；
> ③ 都不行才退 `String` 存毫秒串（本地仍是 64 位 INTEGER，读写时转换）。
> `bytes` 用 `Integer` 没问题（单文件远小于 2.1 GB）。

- 全部字段**不勾非空、不填默认值**（勾了非空就必须给默认值，主键又不许设默认值 —— AGC 会报红卡住）。
- 顺序：先在**开发环境**配好、调通，再「部署到生产环境」；**发布后字段不可删改**。
