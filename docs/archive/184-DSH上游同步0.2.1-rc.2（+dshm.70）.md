## 2. 契约与新增能力

`compat-drift` 对 `alpha.4` 基线实跑：

```text

端点数量        : 期望 144 / 基线 144
```

新增两个上游包：

- `@deepseek-ai/dsh-web-deepseek-api`
  - 由 `dsh-base/cordis.patch.yml` 的 `web-deepseek-api` 行挂载；
  - 注册 `deepseek-search-api` / `deepseek-fetch-api` provider；
  - 纯 JS，沿用现有 `ctx.web`、凭据服务和 jitless fetch 垫片，不新增权限。
- `@deepseek-ai/dsh-client-ui-deepseek-model-label-1017`
  - 由 `dsh-web-app/cordis.patch.yml` 的 `ui-deepseek-model-label-1017` 行挂载；
  - 为官方 Flash 模型名增加临时 `1017` 标签；
  - 只使用现有 UI primitives / locale / model-selection slot。

两个包与 `dsh-llm-pi-ai` 均做了真实 ESM 导入，`apply` 导出均为 `function`。
