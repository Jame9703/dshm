# 第一部分 · 用户可见更新（历史发布文案）

## 一句话

```
1.1.8：内置「启动救援」，插件把界面搞崩也能一键停用恢复；升级 Node 24.9 与新版核心，三端侧栏、连接与任务完成提醒更稳。
```

## 本次更新（10 条）

**1.【启动救援 · 新】** 插件把界面搞崩、只剩 `Failed to load plugins` 时，失败页会出现「启动恢复中心」，可停用肇事插件并重启恢复，**不用卸载重装**。三端内置、默认启用。

**2.【内核与运行时】** dsh 核心升级到 `0.2.2-rc.1`，随包 Node 升级到 **24.9.0**，并修复端侧二进制自签名链路。

**3.【内置终端环境】** PC / 2in1 与手机 guest 环境均内置 **tmux 3.5a、GitHub CLI 2.72**，配合既有 bash / git / Python / pnpm 开箱可用。

**4.【三端形态与侧栏】** 交付面统一为 `entry`（平板 + 2in1）与 `phone`（手机）；平板左栏改为**真常驻**：展开 280、收起 56px 图标轨，点会话区空白不再误收起。

**5.【连接稳定性】** 修复 WebSocket 握手被打断、回环被误判离线、连接循环休眠三条根因；失败后自动退避重连，不用再清进程。

**6.【插件安装 / 卸载】** 修复手持档 `spawn pnpm EACCES`，安装卸载改走进程内队列，「添加插件」不再报错。

**7.【升级与数据安全】** 升级只替换核心运行时，`files/dsh/home` 跨版本共用；会话、工作区、凭据、插件与启停状态均保留。

**8.【账号与登录】** 账号显示改为昵称或脱敏手机号 / 邮箱；华为账号登录收进设置页静默完成，不再跳二级页面。

**9.【后台长时任务】** 修复息屏后长时任务被系统回收导致的后台中断，续期失败自动退避重试。

**10.【任务完成提醒】** 三端任务完成后都会发**状态栏通知**，并由系统通知渠道**响铃提醒**；铃声可在系统设置里单独调整或静音。

# 第二部分 · 详细更新（按主题）

## A. 启动救援插件（本轮新增）

- 包：`@deepseek-ai/dshm-boot-rescue` 1.0.0，源码随仓 `hostcore/plugins/dshm-boot-rescue/`。
- 形态：**纯宿主插件**，零依赖、无 client 半身、不声明 static inject。宿主通过 `webServer.tapIndex` 把 `rescue-client.js` 注入 `index.html`；其它插件全部 pending 时脚本仍会执行。
- 入口：失败页出现 `Failed to load plugins` 且页面没有健康 UI 信号时，挂出「启动恢复中心」（幂等、最多观察 120 秒）。
- 停用：把肇事行 id 写入 `$DSH_HOME/profiles/<profile>/.dshm-plugin-rows.yml`（持久层，重启后仍生效）；只加 3 行带标记的块，不改其它插件行。
- 恢复：恢复中心可单行恢复 / 批量恢复（二次确认）；恢复后同样需划掉后台重开。
- 降级：定位不到数据目录时只读；用户行文件结构异常时改用 profile 的 `cordis.patch.yml` 追加块，并明确提示"重启后失效，请尽快卸载肇事插件"。
- 默认启用：核心树 `profiles/ondevice/cordis.patch.yml` ⑮ 的 insert 行；升级时种子重拼自动到位，不需要用户手动安装。
- 门禁：`tools/check-boot-rescue.mjs`（13 项）钉住包名、入口、无 static inject、tapIndex 注入、pack-core 清单与 profile 行。

## C. 三端形态

- `entry`：`deviceTypes = [tablet, 2in1]`，一份 HAP 同时服务平板、PC、2in1、MatePad Edge / Pro Max。
- `phone`：`deviceTypes = [phone]`。
- `hostruntime`：共享 HSP，`deviceTypes = [phone, tablet, 2in1]`，核心树只放这一份。
- 运行时形态仍由 `DeviceFacts` 判定：PC / 2in1 走桌面档；Edge / Pro Max 强制桌面档；单形态平板保持平板布局（不因 entry 声明 2in1 改变布局）。
- 侧栏：平板展开 280 / 收起 56px 图标轨；侧栏列强制 in-flow，隐藏官方抽屉遮罩；收起态轨内只留一颗 ⊞；不自动收起、不自动补点。
- 返回链：手机 / 平板侧滑逐级返回（面板 → 侧栏 → 页面），PC 分支不动。

## D. 连接与日志

- 侧栏垫片不再改写 WebSocket 握手路径；回环地址不再被 `navigator.onLine=false` 误判为离线。
- 连接失败改为退避重连；最长休眠路径已封死。
- 运行日志支持一键取证（导出诊断包），云调试只抓默认域的问题已修正（关键诊断行改用默认域）。

## E. 插件与数据

- 插件页安装 / 卸载：`viewProfilePackage` 补桥 + pnpm 启动器原子落位 + 进程内队列；手持档不再触发 `spawn pnpm EACCES`。
- 启动自愈：上次启动失败时隔离用户行文件（改名保留，不删除），本次以纯种子启动；坏行预检不拼、不删。
- 数据布局：`files/dsh/home` 跨版本共享；`cores/` 按核心版本独立，可回退旧核心而不影响用户数据。
- 内置插件清单 12 项，全部由 `tools/pack-core.mjs` 单一清单落树；新增 `dshm-boot-rescue`。

## F. 账号 / 设置 / 云同步现状

- 账号显示：昵称优先，其次脱敏手机号 / 邮箱；不再显示脱敏 UnionID。
- 华为账号登录：设置页内静默授权，不再跳二级页面。
- 模型配置：保留官方通用自定义模型 API；原 PC / 2in1 本地模型零代码配置承诺已撤回，不再提供专用入口与接入说明，已有配置与凭据保留。
- **云同步（已知问题）**：当前沿用华为云空间端云同步，范围仍排除核心运行时及API Key、插件只同步清单。跨设备插件清单覆盖及上传完成确认问题本轮暂缓，不作为已验收能力；不删除用户已有本地数据与同步配置。

## G. 权限与上架

- entry 17 条、phone 9 条，逐条有 reason 与 usedScene；无孤儿 reason。
- 新增两条普通权限：`GET_NETWORK_INFO`（连接判定）、`RUNNING_LOCK`（后台续期）。
- release Profile：`app_gallery`、7 条 ACL 与包内一致、未过期。
- 0 个 APK：全仓文件、目录、随包归档条目三面为 0。
- 会议模式及其权限依赖已移除。

## H. 任务完成通知

- 三端（手机 / 平板 / PC）在 Agent 任务完成或失败时都会发布状态栏通知，走系统通知渠道，**由系统渠道音负责铃声**（应用不常驻播放音频）。
- 完成类通知使用 `CONTENT_INFORMATION` / `SOCIAL_COMMUNICATION` 高优先级渠道；若目标机型把渠道建成静音，启动时会自动重建并回读诊断，必要时切换到带声音的社交通信渠道。
- 同一任务的"进行中 → 完成"会先撤销旧通知、再用新 ID 发布，避免系统把更新当成静默刷新而不响铃。
- 铃声大小 / 静音完全由用户在系统设置里控制；应用侧不再单独持有 `DoneSound` 播放器（防止与系统铃声叠响）。
