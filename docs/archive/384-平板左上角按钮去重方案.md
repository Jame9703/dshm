# 384-平板左上角按钮去重：展开态只用官方那颗，收起态才用我们的 ⊞（方案，待确认）

> ✅ **结论已落地并被后续修订**（2026-11-06）：展开态只用官方那颗、收起态才显示 ⊞；但「只保留官方按钮」这一条按 385/386 调整为「官方 56px 轨内按钮不可见 ⇒ 收起态用自绘 ⊞」。以 [`docs/385`](385-平板侧栏回归官方56px图标轨折叠方案.md) 为准。

- 日期：2026-11-06
- 状态：**方案，待确认**
- 现象（用户截图）：平板左栏常驻已生效，但**展开时左上角同时有两颗按钮**——我们自绘的 ⊞ 压在 DSHM 字标上方，而 DSHM 字标右边官方本来就有一颗面板图标（`IconPanelLeftOutlineRegular`）。视觉上"违和"。

---

## 1. 结论

平板档的按钮不该"常驻自绘"，应该按状态分工：

| 状态 | 用哪颗 | 说明 |
| --- | --- | --- |
| **展开** | **官方那颗**（DSHM 字标右边） | 官方在侧栏头里本来就有 toggle（`aria-label` = 收起侧边栏），点击即收起；我们的 ⊞ 隐藏 |
| **收起** | **我们的 ⊞** | 侧栏列宽 0，官方那颗随列一起被裁掉（`overflow:hidden`）⇒ 必须有页面里的备份入口，位置仍在左上角（与手机一致） |

一句话：**我们的 ⊞ 只在"收起态"出现**，展开态完全交给官方那颗。

## 2. 为什么现在会两颗

上一版为了"平板没有入口"加了 `html.dshm-tablet #fab{display:flex}`（无条件常驻）。而实际截图证明：**展开态官方那颗是存在的**（在侧栏头、DSHM 右侧），所以平板根本不需要常驻自绘按钮。

## 3. 改动（只动 phone 壳垫片）

### 3.1 FAB 显隐

```diff
- html.dshm-tablet #dshm-sidebar-fab{display:flex}                       /* 无条件常驻 */
+ html.dshm-tablet[data-dshm-sidebar="collapsed"]  #dshm-sidebar-fab{display:flex}
+ html.dshm-tablet[data-dshm-sidebar="expanded"]   #dshm-sidebar-fab{display:none !important}
```

（收起态出现的位置与尺寸沿用手机那套：左上 6px、36×36、官方同款图标。）

### 3.2 官方按钮点击要同步我们的意图

现在 `document.addEventListener('click', …, true)` 里只写 `manualTabletCollapsed`，没改 `tabletWantsExpanded`。于是用户点官方那颗收起后，`syncState()` 仍按 `tabletWantsExpanded=true` 把状态写回 expanded ⇒ **收起又被顶回来**。改成：

```js
if (has(COLLAPSE_LABELS, label)) {   // 用户点「收起侧边栏」
  tabletWantsExpanded = false; manualTabletCollapsed = true;
  applyState('collapsed', '(tablet user)');
  return;
}
if (has(OPEN_LABELS, label)) {       // 用户点「打开侧边栏」（收起态偶尔出现的官方入口）
  tabletWantsExpanded = true; manualTabletCollapsed = false;
  applyState('expanded', '(tablet user)');
  return;
}
```

- 只在平板档改写这两个变量；手机档行为不变（仍只记 `manualTabletCollapsed`）。
- `programmaticToggleClick` 期间的点击照旧忽略（那是我们自己去点官方按钮，不算用户意图）。

### 3.3 收起 → 展开的回路

收起后只剩我们的 ⊞：点击翻转 `tabletWantsExpanded = true` → 写 `expanded` → 几何恢复 280px，同时 `clickToggle()` 尽力把官方状态也翻过来（让 React 渲染全宽内容）。

## 4. 门禁

`tools/check-phone-sidebar-core-compat.mjs` 的平板段改为：

- 平板 FAB 必须**只**在 `[collapsed]` 出现（`[expanded]` 必须有 `display:none`）；
- 平板不得再出现「无条件显示 FAB」的规则（`html.dshm-tablet #fab{display:flex}` 判红）；
- 官方按钮点击必须同时改 `tabletWantsExpanded` 与 `manualTabletCollapsed`；
- 变异体补 2 个（M18 恢复无条件常驻、M19 官方点击只改 manualTabletCollapsed）。

## 5. 验收

| 场景 | 期望 |
| --- | --- |
| 平板展开态 | 左上角**只有 DSHM 字标 + 右边那颗官方按钮**，没有我们的 ⊞ |
| 点官方那颗 | 左栏收起，⊞ 出现在左上角 |
| 点 ⊞ | 左栏展开，⊞ 消失、官方那颗回来 |
| 打开右栏 / 切会话 | 左栏不收（沿用上一版逻辑，不受本次改动影响） |
| 手机 | 完全不变 |

## 6. 不做的事

- 不加版本号（保持 **1.1.8 / 1010015**）。
- 不改平板几何、不改官方 `data-sidebar-*` 语义、不动权限面。
