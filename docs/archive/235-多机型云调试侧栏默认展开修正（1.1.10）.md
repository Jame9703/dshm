## 2. 根因

旧的侧栏自愈条件只覆盖：

```text
html.dshm-handheld && window.innerWidth >= 900
```

因此有两处漏网：

1. 云调试里部分平板安装/命中的是 `entry(2in1)` HAP，HTML 标记是
   `dshm-pc`，不属于 `dshm-handheld`；
2. `tablet` 竖屏的 CSS 视口常低于 900，被宽度门槛拦住。

结果官方侧栏保持收起，用户看到主区但默认没有左侧内容。

## 3. 修法

一次性自动展开改为：

- `dshm-handheld`（平板）或 `dshm-pc`（PC / 2in1 / Edge）均参与；
- 平板含竖屏，不再要求宽度 ≥ 900；
- 只有 `dshm-compact`（手机 / 折叠屏单屏）在窄视口下保持不抢开；
- 仍等待官方 toggle 与明确 collapsed 状态后才执行，全程只试一次。

左侧浮动入口在状态未知时继续默认可见。
