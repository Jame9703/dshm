## 1. 为什么方案 A 在手机上不成立

### 1.1 官方源码实证

`@deepseek-ai/dsh-client-ui-settings-account/lib/client.js`：

```js
function AccountMenu({ ..., wide, ... }) {
  ...
  Menu({ open, side: "top", portal: true, anchor: button({ "data-collapsed": !wide, ... }), ... })
}
```

**账号菜单是侧栏里的一颗按钮**（`data-collapsed` 由 `wide` 决定），不是一个独立的悬浮入口。

### 1.2 手持档侧栏的真实状态

`WebApp.ets` 头注（§A/§B/§D）早就写明：

> §B 手持档 + 窄屏 ⇒ 侧栏改成**覆盖式抽屉**……
> §D 手持档收起态 ⇒ 页面内**补一颗浮动开关**（handheldFab）……
> 原生顶栏在手持档整条不渲染（"移动端 APP 是没有顶栏的"），而官方那颗按钮长在侧栏列里
> —— 列被 §A 压成 0 宽后它自己也点不到了。

**结论**：手机上要先点 ⊞ 打开抽屉 → 才可能看到账号区 → 才可能看到菜单。
这条路径既深又不稳定，**"往菜单里插一项"等于把入口藏在第三层**。

### 1.3 我在 315 里的判断错在哪

当时假定「账号菜单三端都在」，实际是：

| 端 | 账号菜单 | 顶栏 | 结论 |
|---|---|---|---|
| PC / 2in1 | ✅ 侧栏常显 | ✅ | 两个入口都可用 |
| 普通平板 | ✅ 侧栏常显 | ✅ | 同上 |
| **手机 / 折叠屏** | ❌ 藏在抽屉里、未必可达 | ❌ 整条不渲染 | **两种方式都没有入口** |

## 2. 修正方案：手持档原生浮钮

### 2.1 位置：右上（不与 ⊞ 抢）

```text
┌─────────────────────────────┐
│ [⊞]                   [☁]   │   ← ⊞ 左上 6px；☁ 右上 8px
│                             │
│        页面内容              │
└─────────────────────────────┘
```

⊞ 在左上（`top/left = 6px`），云同步在**右上**（`top/right = 8px`），两者不重叠。

### 2.2 显隐判据：与 ⊞ 完全同口径

| 条件 | 表现 |
|---|---|
| 收起态（`data-dshm-sidebar="collapsed"`）+ 手持/PC 模式 | **显示** |
| 任何面板打开（`data-dshm-panel="open"`） | 隐藏（面板自带返回，留着只会压住顶部按钮） |
| 右侧栏打开（`data-sidebar-right-open`） | 隐藏（与 ⊞ 同口径） |
| 普通平板（`dshm-tablet`） | 隐藏（它有原生顶栏菜单） |

**只依赖我们自己挂的类名与属性，不认官方哈希类名** —— 与 ⊞ 同一条纪律。

### 2.3 与既有入口共用一条路径

```js
el.addEventListener('click', function () {
  var b = window.__DSHM_BRIDGES__;
  if (b && typeof b.openCloudSync === 'function') { b.openCloudSync(); }
});
```

三个入口（顶栏菜单 / 账号菜单注入 / 浮钮）**全部调用同一个桥** `openCloudSync`
→ 打开同一个 `CloudSyncSettings` 面板。不是三套逻辑。

## 3. 本轮踩的坑（第三次同类）

插入 `ensureCloudFab` 后编译报：

```text
Use explicit types instead of "any", "unknown" (arkts-no-any-unknown)
',' expected.
```

**根因**：我在垫片注释里写了 `` `AccountMenu` `` —— 那个**反引号提前闭合了 ArkTS 模板字符串**。

这与 AGENTS.md 坑库记录的**前两次事故**完全同类：

1. 侧栏垫片注释里的 `` `__DSHM_BRIDGES__` ``；
2. 设置垫片注释里的 `` `dsh-client-ui-settings-account` ``。

**已修复**，并做了全文件扫描：670 个模板串，无未转义反引号。

> 教训强化：**垫片模板串内的注释一律不用反引号**，写类名/函数名直接用裸词。

## 6. 测试方法

**重点在手机上验**：

1. 装包、打开应用；
2. **右上角应出现一个云形按钮**（⊞ 在左上，两者分开）；
3. 点它 → 打开云同步面板；
4. 打开侧栏抽屉 / 任何面板时，该按钮应自动隐藏。

PC 上仍可用顶栏「云同步」菜单或账号菜单里的「云同步」项。

## 7. 三个入口的最终分工

| 端 | 顶栏菜单 | 账号菜单注入 | 手持浮钮 |
|---|---|---|---|
| PC / 2in1 | ✅ 主入口 | ✅ 兜底 | 仅 PC 模式收起态 |
| 普通平板 | ✅ 主入口 | ✅ 兜底 | ❌（有顶栏就够） |
| **手机 / 折叠屏** | ❌ 无顶栏 | ❌ 菜单不可达 | ✅ **主入口** |
