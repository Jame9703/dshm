# 392-平板 / 折叠屏展开：左栏「真常驻」收口（去抽屉、去点外收起、按钮常可见）

- 日期：2026-11-07
- 输入：`2026-11-07 18_05_11.log`（平板，24,829 行）、`18_08_41.log`（ProMax/Edge）、`18_13_15.log`（折叠屏）
- 触发：用户「普通平板终于正常显示了，但左侧栏还是不常驻，首次进入要点按钮才出现；点会话区空白处就收回去，且收回去之后按钮也不见了」「折叠屏展开后左栏常驻、不再用按钮呼出、界面不像直板机那样悬浮」「ProMax/Edge 没问题，继续走 PC，不需要平板适配」
- 状态：**已落地**（代码 + 门禁 + AGC 包）

---

## 1. 日志先说清楚

平板日志（`18_05_11`）里唯一一组侧栏记录：

```
[dshm-sidebar] state collapsed, grid=55.9968px 1362.23px 0px (tap 乐观)
[dshm-sidebar] tablet: 左栏被收起 ⇒ 补点展开（常驻 280）
[dshm-sidebar] state expanded, grid=55.9968px 1362.23px 0px (tap 乐观)
[dshm-sidebar] toggle collapsed -> expanded, frame=expanded
[dshm-back] consume: drawer
```

三条关键读数：

1. `grid` 第一条轨道**始终是 56px**（展开态也没到 280）⇒ 官方仍按 **narrow / drawer** 渲染这条列；
2. `[dshm-back] consume: drawer` ⇒ 当前是抽屉形态；
3. 官方抽屉 CSS 里 `.sidebarCol{z-index:71; position:absolute}`、`.drawerMask{z-index:70}` —— 我们的 ⊞ 是 `z-index:60`，**被遮罩和侧栏列压在下面**，所以"收起后按钮不见了"。

抽屉形态同时解释了另外两个现象：展开时侧栏是覆盖式浮层 ⇒ 点会话区空白处 = 点遮罩 ⇒ 官方收起；首帧默认 `narrowExpanded=false` ⇒ 首次进入必须点一下才出来。

## 2. 方案：不再把几何交给官方

前几轮按 docs/385 把平板几何"交还官方"，前提是"官方在这台机器上会给出 280 / 56 两档"。真机证明这个前提不成立（它走的是 narrow/drawer）。

本轮改为**平板档自己掌控几何**，但状态仍然只认官方：

- 状态：`data-sidebar-collapsed`（官方 frame 属性）；
- 点按：仍然点官方 toggle（不自己维护"展开/收起"另一套状态）⇒ 不会重演 docs/385 §2 的"两套状态各说各话"。

具体：

| # | 改动 | 目的 |
| --- | --- | --- |
| ① | `html.dshm-tablet[expanded] .dshm-frame{grid-template-columns:280px minmax(0,1fr) 0}` | 展开恒定 280，不受官方 narrow 影响 |
| ② | `html.dshm-tablet[collapsed] …{grid-template-columns:56px …}` | 收起只缩到 56px 图标轨 |
| ③ | `html.dshm-tablet .dshm-sbcol{position:relative;inset:auto;transform:none;visibility:visible;…}` | 侧栏列回到常规流，**不再是悬浮抽屉** |
| ④ | `html.dshm-tablet [class*="drawerMask"]{display:none;pointer-events:none}` + JS 每拍 `frame.removeAttribute('data-sidebar-drawer')` | 点会话区空白不再收起 |
| ⑤ | `html.dshm-tablet #fab{z-index:80}` + 收起态 `display:flex` | 收起态按钮永远在遮罩之上，看得见点得到 |
| ⑥ | 收起态把轨内官方 opener 交给 ⊞；展开态官方「收起侧边栏」保持可见 | 同一列只留一颗按钮，收起/展开各一颗 |

补点节奏也改了：800ms → 2s → 5s 退避、上限 40 次（原 15 次会在一次异常后"永久放弃"，此后官方每次重置都不再恢复）。

## 3. 折叠屏展开 = 平板档（手机壳）

`phone` 壳本来就按 `platformForm()` 把「折叠屏展开」标成 `dshm-tablet`（`setFlag(…, TABLET_CLASS, … (foldable && !compact))`），但 CSS 里这一档**一条几何都没有** ⇒ 跟着官方走抽屉。

本轮把同一组平板规则（①–⑥）补进手机壳，并同样每拍摘 `data-sidebar-drawer`。直板机（`dshm-compact`）与折叠单屏的抽屉、⊞、点外收起**一个字节不动**。

## 4. ProMax / MatePad Edge

用户口径：这两台继续走 PC 端，不做平板适配。它们的 `DeviceFacts.desktopForced` 为真 ⇒ `form=desktop` ⇒ 不挂 `dshm-tablet`，本轮所有平板规则都不命中，行为不变。

## 6. 真机待验

1. 平板首次进入：左栏直接 280，不需要点按钮；
2. 点会话区空白：左栏不再收起；
3. 点官方「收起侧边栏」：缩到 56px 轨，⊞ 仍在轨内居中、可点；
4. 折叠屏展开：同平板（常驻、非悬浮）；折叠回单屏：仍是手机抽屉；
5. ProMax / Edge：PC 形态不变。
