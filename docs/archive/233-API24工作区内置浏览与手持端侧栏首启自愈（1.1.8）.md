## 2. API 23–25 工作区选择

系统文件夹选择能力缺失时，不再静默返回专属下载目录，而是保持 Web 侧
`pick()` Promise pending，并弹出应用内工作区浏览器：

- 应用下载目录：`Download/com.dshm.dshclient`；
- 应用沙箱：`<filesDir>/workspace`；
- 支持切换根目录、进入子目录、上一级、新建目录、取消、确认；
- 只有用户明确确认后才把路径交回 Web 侧；
- 诊断文件记录
  `diag-workspace-browser-open` / `-choice` / `-cancel`。

权限面没有增加。API 23–25 仍不能访问任意用户目录，这是平台能力边界；
当前方案提供的是应用确实可读写的完整可选范围。

## 3. 手持端侧栏首启自愈

### 3.1 状态未知时仍保留入口

在 `<html>` 尚无 `data-dshm-sidebar` 时，左侧浮动入口默认显示：

```css
html.dshm-handheld:not([data-dshm-sidebar]) #dshm-sidebar-fab {
  display: flex;
}
```

官方 toggle 出现并给出明确 `collapsed` / `expanded` 后，再按真实状态收口；
右侧栏或设置浮层打开时仍优先隐藏入口。

### 3.2 自愈计时从“侧栏真正挂载”开始

旧顺序：

1. shim 安装即开始 15 秒计时；
2. 找不到官方侧栏时直接 `autoTried = true`。

新顺序：

1. 先等待官方 toggle 与明确状态；
2. 状态首次可读后才开始 15 秒时间窗；
3. 仅在 `collapsed` 时自动点开一次；
4. 官方已是 `expanded` 时只锁状态，不抢用户操作。
