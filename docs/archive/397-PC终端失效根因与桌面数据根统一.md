# 397-PC 终端失效根因（新 entry 壳的数据目录不在可加载命名空间）与数据根统一

- 日期：2026-11-07
- 输入：`20_47_48.log`（PC）、`20_49_57.log`（MatePad Edge / ProMax）
- 状态：**已修复并出包待验**

---

## 1. 三端到底走哪个模块（日志实证）

| 设备 | 模块（mission/moduleName） | Host 数据根 |
| --- | --- | --- |
| 鸿蒙 PC / 2in1 | **`pc`** | `/data/storage/el2/base/haps/pc/files` |
| MatePad Edge / ProMax | **`entry`**（tablet 面） | `/data/storage/el2/base/haps/entry/files` |
| 手机 | `phone` | `/data/storage/el2/base/haps/phone/files` |

PC 日志：`DMSContinue… moduleName: pc abilityName: EntryAbility`；核心安装与 Host 启动都发生在
`haps/pc`。

## 2. 唯一的硬错误

```
W MUSL-LDSO: load absolute_path /data/storage/el2/base/haps/pc/files/dsh/cores/0.2.2-rc.1+dshm.1/
             node_modules/node-pty/prebuilds/openharmony-arm64/pty.node:
             check ns accessible failed namespace=moduleNs_default
W MUSL-LDSO: … failed, namespace=default no inherits, errno=2
```

`errno=2`（ENOENT）不是文件不存在，而是**该路径不在调用方的可加载命名空间**里。
`dlopen` 被拒；同一目录下的 `execve` 不受影响（Host 的 `node` 就是从这里跑起来的）。

## 3. 为什么判定是"模块数据目录"而不是"打包缺件"

把拆分前的 `entry-default.hap`（121940 包）与现在的 `pc-default.hap`（124125 包）逐项比对：

- 文件清单：**74 : 74，完全一致**；
- `libc++_shared.so` / `libdshhost.so` / `libdshm-gitcompat.so` / `libentryprobe.so`：**大小与 sha256 全部相同**；
- `pack.info` 的模块元数据：只有 `moduleName` 与 `deviceType` 不同。

⇒ 内容没问题，差异只可能来自**模块身份**：端侧只把主入口模块（`entry`）的数据目录挂进应用的可加载
命名空间，新加的 `pc` 壳自己的 `haps/pc/files` 不在其中。

旁证：手机日志里同样有这条 `pty.node` 失败（手机的终端走 guest VM，不依赖它，所以从未暴露）。

## 4. 修复：桌面形态的数据根统一到主入口模块

`hostruntime/src/main/ets/runtime/HostModules.ets` 新增：

```ts
export function resolveHostDataDir(ownFilesDir: string, desktop: boolean): string
```

- 桌面形态（`!isHandheldForm()`）且当前不是 `entry` 模块 ⇒ 若 `haps/entry/files` 存在，
  返回它；否则回退到自己的目录；
- 手机 / 平板不进入这条（保持各自沙箱）。

两个壳（`entry` / `pc`）的 `EntryAbility` 都用它作为 `NodeRuntime` 与 `DshHost` 的数据根。
因为两壳源码逐字相同，`check-pc-tablet-parity` 依旧通过。

**副作用（正向）**：PC 升级后仍然吃 `haps/entry/files` 里原有的核心、会话与插件，
不会因为换了壳而"丢数据 + 重新解包 108MB"。

## 5. 边界

- 全新 PC（从未启动过 `entry`）上 `haps/entry/files` 不存在 ⇒ 回退到自己目录，
  仍可能复现 `dlopen` 被拒。若真机复现，下一手是**把 `pty.node` 放进门 HAP 的 `libs/`**
  （`libdshm-pty.so` + `process.dlopen` 兜底），彻底绕开数据目录限制。
- Edge / ProMax 继续走 `entry`（tablet 壳）+ `desktopForced` 运行时 PC 形态，
  系统标签不是「PC 应用」——docs/239 的既定取舍。
