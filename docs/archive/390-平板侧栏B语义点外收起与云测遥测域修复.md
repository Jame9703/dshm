## 2. 云测遥测盲区（本轮最大发现）

**事实链**：

- `EntryAbility` 的 hilog 用 `domain=0x0000`（TAG `entry/ability`）⇒ 其在云测日志里**全部可见**。
- `WebApp` 此前恒用 `domain=0xD5D5`（TAG `DshWebApp`）⇒ 云调试抓取只收默认域（`A00000` 前缀）的应用行，**一条都不可见**。
- 三份云测日志（`2026-11-07 08_38/08_40/08_42`）中 `[web]` / `[dshm-sidebar]` / `DshWebApp` 命中数均为 0 —— 即此因；`.onConsole` 另有一路落盘 `files/diag-web-console`，但本机无 hdc，文件取不出来，云测环境同样拿不到。

**修法（最小改动面）**：新增 `CLOUD_DOMAIN = 0x0000`，只用于两条取证通道：

1. `.onConsole` 的 `[web] <source>:<line> <level> <message>` 转发（垫片 `console.info('[dshm-sidebar] …')` 由此外显）；
2. `.onPageEnd` 的**版本锚点**：`bundleManager.getBundleInfoForSelfSync` 打 `[dshm-web] version=<versionName> (<versionCode>)`，每次页面结束（含失败轮）都打 ⇒ 任何日志窗口都能对版本。

其余 `0xD5D5` 调用不动（本地 DevEco 过滤习惯不变）。

**新增取证行（垫片内，纯字符串拼接、不新增模板插值）**：

- 启动：`boot vw=<w>x<h> dpr=<dpr> state=… frame=…` —— 直接回答「云测平板真实 CSS 视口是不是 1198×682」。
- 12s 快照（`diagToggle` 追加）：`diag vw=… dpr=… tablet=… layer=… manualCollapsed=… drawer=… state=…`。

## 4. B 语义：点侧栏外收回 56px 轨（用户裁决）

**语义边界**（用户原话归纳）：

- 启动默认展开：**不**拦截内容点击（不设闩）。
- 用户从 56px 轨**手动展开**后：点侧栏列外任意处 ⇒ 收回官方 56px 轨。
- 收回记作**手动收起**（`manualTabletCollapsed`）⇒ `ensureTabletExpanded`（keep-open）与 `maybeAutoExpand` 都尊重该闩，不再把栏顶回来。
- 用户再点轨内 toggle 展开 ⇒ 闩重新生效（可反复）。

**实现**（`entry/src/main/ets/pages/WebApp.ets` 的 `SIDEBAR_SHIM_JS`）：

- 新闩 `tabletLayerOpen`：官方 toggle 的「打开侧边栏」文案被点 ⇒ 置真（`isTablet` 时）；「收起侧边栏」⇒ 置假（并入原手动监听）。
- 新捕获阶段 `click` 监听，命中条件（顺序即判据）：
  1. `isTablet` 且非程序化点击（`programmaticToggleClick`）；
  2. **先判列内**：事件目标到 document 的祖先链上没有 `dshm-sbcol` —— 轨内那颗 toggle 就在列里，必须先短路，否则「点轨展开」会被自己当成点外收起再点回去；
  3. 闩 `tabletLayerOpen` 为真；
  4. 无面板/右栏打开、非抽屉档（这两种官方自有权重，不掺和）；
  5. 当前读数 `state() === 'expanded'`。
- 命中 ⇒ `tabletLayerOpen=false`、`manualTabletCollapsed=true`、记日志、`clickToggle()`。
- 用捕获阶段：目标元素的 React `stopPropagation` 不会让动作漏掉；不阻断传播，目标交互照常。

## 5. 平板 FAB 规则连带命中（静态缺陷，已修）

`dshm-handheld` 的两条规则未排除 `dshm-tablet`：

- `html.dshm-handheld[data-dshm-sidebar="collapsed"] #dshm-sidebar-fab{display:flex}` ⇒ 平板收起态凭空多一颗自绘 ⊞（与官方 56px 轨内 toggle 重叠）；
- `html.dshm-handheld[data-dshm-sidebar="collapsed"]{--dsh-frame-leading-clearance:66px}` ⇒ 平板没有 ⊞ 却让位 66px（标题行错位）。

两条均改为 `html.dshm-handheld:not(.dshm-tablet)…`。phone 壳不涉及（其 FAB 规则挂在 `dshm-compact` / `dshm-pc` 上，折叠多屏非 compact，无此缺陷）。
