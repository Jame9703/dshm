# 411 「内容由 AI 生成」标识只贴在会话输入座位

**问题**：移动端右侧边栏里出现了「内容由 AI 生成」。用户口径：这条披露只允许出现在会话区输入框**上方**，其它位置一律不显示，不在会话页时彻底不显示。

**根因**：壳内垫片 `AI_DISCLOSURE_SHIM_JS` 用 `[class*="composerSeat"]` 找座位、取**面积最大**的一个挂上去。右侧边栏同样可能渲染会话输入座位（子会话 / 预览面板），主会话尚未渲染时就会挑中右栏那一个 —— 标识于是跟着跑到右栏。

**改动（entry / phone 两壳同一份逻辑）**

1. 首选官方稳定属性 `[data-composer-seat]`（核心自己就用它定位输入座位：`root.closest("[data-conversation-scroll]").querySelector("[data-composer-seat]")`）；类名兜底只在**一个 data 座位都没有**时才触发。
2. 新增 `inSidePanel(el)` 祖先判定：命中 `data-rightbar-col`（右栏列）、`data-global-panel`（全局浮层）、`role="dialog"` 的座位一律跳过。
3. 没有可用座位 ⇒ `place()` 走 `detach()`，把节点从 DOM 摘掉（不是 `display:none`，避免残留被截图 / 读屏看到）。

**结果**：标识只随主会话输入卡片出现与消失；右栏、设置、插件页、文件预览一律不显示。

**门禁**：`tools/check-ai-disclosure-scope.mjs`（两壳同判：锚点、右栏排除、兜底条件、无座位即摘除、脚本语法可解析；4 个变异体必须判红）。

**未做（用户裁决）**：插件页 / 设置插件页 / 会话正文的宽度上限（`960 / 760 / clamp(680, 列宽×0.64, 920)`）**保持上游原值**，不做自有覆盖 —— 宽度跟随 dsh 官方设置（会话正文可用官方宽度手柄调整）。
