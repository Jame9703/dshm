# 262 · 普通平板 PC 顶栏回归与侧栏入口接管

> 日期：2026-10-25
>
> 基线：`1.1.6 / 1010007`，核心 `0.2.1-rc.3+dshm.96`
>
> 范围：普通平板 `deviceType=tablet` 且 `desktopForced=false`；不改核心。

## 1. 用户口径

普通平板恢复 1.1.3 时代的 PC 风格顶栏：

- 顶栏与 PC 端相同，左上角是原生侧栏按钮；
- 顶栏横竖屏都常驻；
- 左侧边栏默认展开并保持常驻；
- 官方 Web UI 内「DeepSeek Harness」字标右侧的「收起侧边栏 / 打开侧边栏」
  按钮隐藏，由原生顶栏按钮接管；
- 手机、折叠屏、MatePad Edge、MatePad Pro Max 与普通 PC / 2in1 的其他行为不变。

## 2. 实现

### 2.1 顶栏策略

`shouldShowAppTopBar(rawType, desktopForced, landscape)` 只对
`rawType=tablet && !desktopForced` 改为恒显：

```text
phone                                      => false
tablet + desktopForced                     => 原横屏策略
tablet + !desktopForced                    => true
PC / 2in1                                  => true
```

Edge / ProMax / MateBook 在设备事实层已是 `desktopForced=true`，不会进入普通
平板的新增分支。

### 2.2 侧栏入口与常驻

普通平板由原生桥报告为 `platformForm()==='tablet'`，侧栏垫片补挂独立
`dshm-tablet` 标记：

- 官方 Web 侧栏按钮用中英文两条 `aria-label` 规则隐藏；同时保留 300ms 巡检的
  内联隐藏，React 重建节点后能自愈；
- 不创建页面浮动侧栏入口；
- 普通平板排除在手机 / 折叠屏的覆盖式抽屉媒体规则之外；
- 侧栏展开时使用官方内联三列布局；用户主动收起后保留官方 `56px` 窄轨；
- 启动、右栏开关或 React 重排造成的非用户收起会恢复左栏；
- 原生顶栏点击携带 `manual=true`，用户主动收起后巡检不会抢开；再次点击可重新展开。
