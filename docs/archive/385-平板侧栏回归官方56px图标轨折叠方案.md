# 385-平板侧栏回归官方「56px 图标轨」折叠（方案，待确认）

> ✅ **状态回写：已落地**（2026-11-06 出包）。本档与 [`docs/386`](386-三端分离重整方案-PC平板手机各走各的.md) 共同构成当前平板/三端口径的出处。

- 日期：2026-11-06
- 状态：**方案，待确认**
- 现象：平板默认展开 ✓、左上角没有多余按钮 ✓；但**手动收起后再点 ⊞，会"弹一下但出不来"**。
- 用户口径：只用官方那一颗原生侧边栏按钮；收起时侧栏**只是缩小成一列**（不是完全看不见），按钮就在那一列里；平板按这个改，手机/PC 不动。

---

## 1. 调研结论：官方本来就有"图标轨"折叠，是我把它盖掉了

`dsh-client-ui-layout/lib/client.js`：

```js
const collapsedWidth = drawer || darwin || windowsTitlebar ? 0 : 56;
const cols = computeColumns(viewport, ..., collapsedWidth, ...);
// computeColumns: sidebar === 0 ? collapsedWidth : clampWidth(sidebar, 264, 420)
```

即：**非抽屉、非 macOS、非 Windows 标题栏** 的设备，左栏收起时**保留 56px 的图标轨**；
展开时是 280（`sidebarPreference` 默认值，clamp 264–420）。

`dsh-client-ui-sidebar/lib/client.js` 里同样有对应实现：

```css
.root.collapsed{ padding:18px 10px 6px }   /* 收起态仍有内容与按钮 */
```
组件里还有一整套 `_rail` 类（22 处）——**收起态渲染的就是图标轨，toggle 按钮就在轨里**。

⇒ 官方在这台平板上**本来就支持"缩小成一条、按钮还在那条里"**。是我上一版加的平板几何
（`grid-template-columns:280px ... ` / `0 ...` + 侧栏列 `width/position` 覆盖）把它盖掉了。

## 2. "弹一下但出不来"的成因

我们同时存在两套几何：

| 谁 | 展开 | 收起 |
| --- | --- | --- |
| 官方 | 280 | **56（图标轨 + 轨内 toggle）** |
| 我们的平板 CSS | 强制 280 | **强制 0（整列消失）** |

点 ⊞ 时：我们把自己的状态写成 `expanded` → 列宽被强行拉到 280；
但**官方 React 状态仍是 collapsed**（我们那次 `clickToggle()` 找不到官方 toggle 或没生效），
于是内容仍是"轨道形态"渲染在 280 宽的盒子里 —— 视觉上就是**弹一下又缩回去/出不来**。

根因不是"被压缩"，是**两套状态各说各话**。

## 3. 落地方案：平板"交还官方"，我们只保留两件事

### 3.1 删除（平板的强制几何与自绘按钮）

- `html.dshm-tablet[state=expanded] .dshm-frame{grid-template-columns:280px minmax(0,1fr) auto}`
- `html.dshm-tablet[state=expanded] .dshm-sbcol{position:relative;width:280px;...}`
- `html.dshm-tablet[state=collapsed] .dshm-frame{grid-template-columns:0 ...}`
- 平板上的 ⊞：`ensureFab()` 在平板档**不再创建**（连同 `[state=collapsed] #fab{display:flex}` 两条规则一起删）

### 3.2 保留（这两件事官方不管，必须我们做）

1. **默认展开**：首帧/静默期结束后，若官方是 `collapsed`，**点一次官方 toggle**（`narrowExpanded=true` ⇒ 280）。
2. **不被右栏/切面板顶掉**：`tabletWantsExpanded=true` 且官方 `collapsed` 时，每 800ms 补点一次。
   - 用户点官方那颗「收起侧边栏」→ `tabletWantsExpanded = false`，补点停止（尊重用户）。
   - 用户点轨道里那颗「打开侧边栏」→ `tabletWantsExpanded = true`，恢复补点。

### 3.3 `syncState` 平板档改为跟随官方

上一版把平板状态改成由我们覆盖（`applyState(tabletWantsExpanded ? …)`），现在几何交还官方了，
状态属性只做诊断：平板档直接 `applyState(state())`（读 `frame[data-sidebar-collapsed]`）。
