## 二、这一版修了什么

| 上一版的问题 | 本版 |
|---|---|
| 点击后**顶栏菜单消失** | 改成**页内浮层**，顶栏始终在 |
| 点击后没生效 / 回不到主页 | 浮层可**点遮罩关闭**、顶部有「‹ 返回」、系统返回键先关登录面板 |

## 三、测试步骤（请严格按顺序）

### 步骤 1：打开面板

1. 启动 DSHM beta
2. 点顶栏 **「应用」** 菜单
3. 点 **「华为账号与云同步」**

**预期**：出现一张半透明遮罩的卡片面板，**顶栏仍在**。

- ✅ 顶栏还在 → 继续步骤 2
- ❌ 顶栏又消失了 / 没反应 → **停，直接进 §五「A 类问题」**

### 步骤 2：点登录

1. 点 **「登录华为账号」**

**预期**：弹出**官方标准登录面板**（华为账号登录页，带协议勾选）。

### 步骤 3：完成登录

- 若弹出面板 → 勾选协议 → 点登录 → 完成授权
- **预期**：回到卡片面板，显示 `已登录 ****xxxx` 和 `authorizationCode: 已获取（N 字符，不回显）`

### 步骤 4：跑 P0 验证链

点 **「运行 P0 验证链」**，等待七行结果出现。

**本步会做**：上传一个测试文本到你的云空间根目录 → 列出来 → 下载回来比对 → 删掉。
**不会读写任何会话数据**（只碰一个 `dshm-probe-p0/probe.txt`）。

### 步骤 5：清理

点「清空暂存目录」，然后**点遮罩关闭面板**（验证能正常收起）。

## 五、按现象分诊

### A 类问题：点了没反应 / 顶栏消失

**这属于 UI 层故障**，请提供：

1. 点击前的截图（能看到「应用」菜单展开）
2. 点击后的截图
3. hilog 里搜 `cloud-probe`、`page/cloud-probe` 的结果

**我们能从日志判断**：
- 若出现 `page/cloud-probe` 的日志 → 面板组件已构建，问题在渲染
- 若完全没有 → 桥没调通或菜单项没绑上

### B 类问题：登录面板弹不出来

| 现象 | 可能原因 |
|---|---|
| 什么都不弹，无日志 | `LoginPanel` 组件未渲染（`showLoginPanel` 没置真） |
| 弹一下就消失 | 面板 `show` 绑定问题 |
| 报 `1001500001` | 证书指纹不匹配（**我们已核对一致，若报这个需贴 hilog 细节**） |
| 报 `1001502014` / `1001500003` | Account Kit scope 未开通 |
| 报 `1001502001` | 系统未登录华为账号 |
| 报 `1005300001` | 用户未接受协议 |
| 报 `1001500002` | 请求处理中（重复点击导致） |

### C 类问题：登录成功但云盘不通

按七步里**第一个 ❌** 定位：

| 卡在 | 含义 |
|---|---|
| ① 能力探测 | 设备/系统不支持该 Kit |
| ② 云盘连通 | AGC 的 CloudFoundationKit 未启用，或 bucket 未创建 |
| ③ 暂存 | 本地 cache 写入失败（少见） |
| ④ 上传 | Drive 服务不可用或权限不对 |
| ⑤ 列表 | 上传成功但列不出来（路径/实例问题） |
| ⑥ 下载比对 | 下载成功但字节不一致（严重，需贴大小） |
| ⑦ 删除 | 删除权限问题 |
