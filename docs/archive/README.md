# docs/archive —— 历史文档（只读）

> 本目录是 2026-11-18 文档体系重整时归档的全部历史编号文档与评审 / 交接快照。
> **只读、不作为现行口径、不参与门禁扫描。**

## 为什么归档

- 旧体系有数百篇编号文档，同一问题多篇并存、互相推翻，接手的人无法判断哪条有效（现归档 350 个 `.md`）。
- 现行体系只保留 4 类文档（规范 / 操作 / 台账 / 决策），见 `docs/README.md`。

## 怎么查

- 原 `docs/<编号>-*.md` → `docs/archive/<编号>-*.md`（编号不变）。
- 完整清单：`MIGRATION.txt`（逐篇列出迁移文件）。
- 旧版 `docs/README.md` / `docs/HANDOFF.md` 快照：`legacy-README-2026-11-18.md`、`legacy-HANDOFF-2026-11-18.md`。

## 使用纪律

1. 追溯根因、看当年读数可以查；**不要**据此改当前实现。
2. 引用归档文档时写 `docs/archive/<编号>-*`，**不要写行号**。
3. 若某条历史结论仍然有效，把它**提炼**进 `docs/FEATURES.md` / `docs/PITFALLS.md` / `docs/DECISIONS.md`，
   而不是把归档文档重新搬回顶层。
