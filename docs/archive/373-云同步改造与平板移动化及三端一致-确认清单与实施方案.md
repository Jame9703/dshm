## 1. 云同步（4 条需求 → 落点与改法）

### 1.1 ① 登录账号显示成"内部代号"

**现状**：设置页云同步分区显示的标识不是手机号/邮箱，用户认不出是谁的账号（像是内部 ID）。

**落点**：`platform/src/main/ets/sync/SyncState.ets`、`SyncActions.ets`、`hostcore/plugins/dshm-cloud-sync/lib/client.js`（设置页渲染）。

**改法**：
1. 登录成功后从账号侧取 `phoneNumber` / `email`（Account Kit 的账号信息），**优先手机号，其次邮箱**；
2. **脱敏展示**：`138****5678` / `ab***@example.com`；
3. 取不到时按序回退：昵称 → `华为账号（已登录）`，并落一行诊断说明"该账号未返回手机号/邮箱"；
4. **unionID / openID 只进诊断文件，不上 UI**（现在的问题就是把内部 ID 当成了展示名）。

**待定（D2）**：脱敏规则用上面这套？取不到时用哪个回退文案？

### 1.2 ② 上传之后怎么存：设备 + 日期

**现状**：当前同步单元是 `session / attachment / skill / plugin_manifest` 平铺，没有"设备 + 日期"这一层。

**建议结构**（云端逻辑目录，不是新建数据库表）：

```
dshm-sync/
  <deviceId>/               # 设备标识：设备名+短哈希，如 "MatePad-Edge-3f2a"
    <yyyy-MM-dd>/           # 上传日期（本地时区）
      manifest.json         # 本次快照的索引：会话数/插件数/字节数/版本/核心版本
      sessions.jsonl        # 会话记录
      plugins.json          # 插件清单（名称/版本/来源 spec/启用状态）
      attachments/          # 附件（按需，默认不进）
```

- `deviceId`：取设备型号 + `deviceId` 短哈希（**不用序列号**，避免隐私与合规问题）。
- 同一天多次上传：**默认覆盖当天快照**（保留最近一份），并在 `manifest.json` 里记 `uploadedAt` 与 `revision`。

**待定（D3a）**：日期按"上传日期"还是"会话最后活动日期"？同日多次上传是覆盖还是保留多版本？

### 1.3 ③ 其他设备登录后选择"哪个设备 + 哪个日期"恢复

**目标交互**（设置 → 云同步）：

```
[账号卡]  138****5678   （退出登录）
[这台设备] MatePad-Edge-3f2a · 今日已上传 14:32
[从其他设备恢复]
   ▸ MatePad-Pro-13.2-9c11      2026-11-04  12 会话 / 9 插件
                                 2026-11-03  11 会话 / 9 插件
   ▸ Pura90Pro-4d7e             2026-11-02   8 会话 / 7 插件
[操作] 上传本机快照 / 刷新列表 / 删除某天快照
```

- 选择某一行 → 二次确认 → 拉取并恢复；
- 恢复内容按用户口径：**会话记录 + 插件清单**（插件**只恢复清单与启用状态，不下载插件包**；缺包时列出"需重装"的项）。

**待定（D3b）**：恢复是**合并**（按会话 id 去重，保留本机）还是**覆盖**（清空本机会话再导入）？建议默认合并 + 明确提示条数。

### 1.4 ④ `code=CLOUD_DISABLED schedule=2` —— 上传"成功"但提示云端未成功

**这是系统侧拒绝端云同步，不是提示 bug**。两条根因（`docs/371` 的 #13 已取证）：

1. `phone / entry` 都**没有** `ohos.permission.DISTRIBUTED_DATASYNC`（源码全仓无此串）⇒ `setDistributedTables(DISTRIBUTED_CLOUD)` 必然失败；
2. AGC 云侧未开通 / schema 不一致（原生错误文案自己写着"多为 AGC 云侧未配置或字段不一致"）。

**代码侧能做**（本轮可做）：
- 把 `CLOUD_DISABLED` / `schedule=2` 这类码**映射成人话 + 下一步指引**（"端云同步未开通：需应用侧权限与 AGC 云配置，不是你的设置问题"）；
- 上传"假成功"要纠正：**本地落库成功 ≠ 云端成功**，UI 必须分开成"已写入本机 / 已上传云端"两个状态位（现在的"上传成功"其实是前者）。

**代码侧做不到**：让 `CLOUD_DISABLED` 变成功。**必须**：ACL 申请 `DISTRIBUTED_DATASYNC` + AGC 云侧开通。这是外部周期（约 1–2 周）。

## 2. 平板端 UI：改成移动端样式（不再与 PC 共用顶栏）

### 2.1 现状

- `dshm-handheld` 已覆盖 phone / tablet / foldable（都挂抽屉与 FAB）；
- 但**平板仍保留原生顶栏**（代码注释："普通平板已有原生顶栏按钮，不再创建第二颗页面浮动入口"），即平板当前是"PC 顶栏 + 手持抽屉"的混合体。

### 2.2 目标（用户口径）

1. 平板**不再用 PC 顶栏**，改移动端样式：左右侧边栏；
2. **默认左侧边栏展开**；
3. 左上角显示 `DSHM`，其**右侧**保留"侧边栏"按钮；
4. **只有用户点按钮才收起**；收起后按钮仍保留（常驻，不随收起消失）；
5. 保证平板**小窗 / 自由窗口拖拽**可用（顶栏自绘不能吃掉系统拖拽区）。

### 2.3 落点

| 文件 | 改动 |
|---|---|
| `entry/src/main/ets/pages/WebApp.ets` | 新增 `dshm-tablet` 档（不再复用 PC 顶栏渲染分支）；`applyHandheld()` 里 tablet 走移动布局；顶栏自绘：左 `DSHM` + 右折叠按钮；收起态仍保留按钮；`dragRegion` 显式标出可拖拽区 |
| 注入 CSS（同文件 `STYLE` 段） | 左右侧边栏布局、默认展开、收起动画、`env(safe-area-inset-*)` 避让 |
| `platform/src/main/ets/...`（窗口状态） | 平板自由窗口/小窗时降级为"浮层侧栏"，避免挡住拖拽 |
| `tools/check-sidebar-shim-css.mjs` | 增加 tablet 档断言（默认展开 / 收起后按钮在 / 拖拽区未被覆盖），带对照臂 |

### 2.4 风险

- 平板还可能进入**自由窗口**（可缩放），侧栏宽度需按窗口宽自适应；否则窄窗会挤爆；
- 自绘顶栏与系统窗口装饰（三键/拖拽条）重叠是历史踩坑点（`docs/` 有记录），必须先量真机 `inset`。

**待定（D4）**：平板是否**彻底**移动化（含自由窗口也走移动布局），还是"全屏走移动、自由窗口保留 PC 顶栏"？建议后者更稳（自由窗口本质是桌面交互）。
