## 2. 本版变化（按影响面排序）

### 2.1 语音听写改走系统语音识别（不再下载模型）

- **变化**：输入框旁的麦克风听写由设备系统语音识别完成，不再依赖随包模型下载；较长语音会自动续接
  （实测连续 **45 秒**说话，文本能完整落进输入框）。
- **怎么验**：
  1. 新建会话 → 点输入框麦克风 → 允许麦克风权限 → 连续说 20–45 秒中文；
  2. 期望：文字逐段出现在输入框（不是一次性、也没有"识别中…一直转"），说完后文本完整；
  3. 再说一段中英混合（如"帮我查一下 API 文档"），期望中英都能出字。
- **注意**：识别质量取决于设备系统语音能力与网络/权限；失败时请记录现象与时间点。

### 2.2 2in1「电脑模式 / 自由窗口」左侧栏入口与窗口缩放

- **修复的现象**（原 AGC 测试版复现）：2in1 平板在电脑模式（自由窗口）下打开 DSHM，
  **左侧没有侧栏入口**，窗口**只能从左下/右下角**缩放；点网页右上角那颗按钮后侧栏才恢复。
- **怎么验**：
  1. 2in1 设备进入电脑模式（自由窗口）；
  2. 打开 DSHM：左上应能直接看到侧栏入口（或收起态有 ⊞ 入口），侧栏可正常展开；
  3. 拖窗口**任意一边/角**都应能缩放（不再只有两个角）；
  4. 最大化 ↔ 自由窗口来回切，入口与缩放行为保持一致。

### 2.3 右侧栏打开时左上角按钮与标题重叠

- **修复的现象**：打开右侧栏（文件预览 / 终端 / 浏览器）时，左上角浮动 ⊞ 压住面板标题文字。
- **怎么验**：打开右侧栏 → 左上角不应再出现 ⊞ 遮挡；关闭右侧栏后 ⊞ 恢复。

### 2.4 右侧栏打开时返回手势直接回桌面

- **修复的现象**：打开右侧栏后，用系统返回手势/返回键，应用直接退到桌面。
- **怎么验**：打开右侧栏 → 返回手势/返回键：期望**先关闭右侧栏回到会话区**；再返回才退回桌面。

### 2.5 卡顿与"界面卡死"（Host 事件循环阻塞）

- **修复的现象**：以下场景界面会出现长卡顿（数秒到数分钟点不动、输入无响应）：
  - 插件安装/更新、皮肤市场落位；
  - 在会话里让 Agent 执行耗时较长的 Python（例如 `pip install`）、长脚本或长命令；
  - 使用久了偶发的周期性 8 秒卡顿（慢存储设备更明显）。
- **改法**：长任务移出界面主线程；同时减少了对慢存储路径的重复探测。
- **怎么验**：
  1. 安装一个插件/皮肤，安装过程中点击侧栏、切换会话：界面应保持可点、可滚动；
  2. 让 Agent 执行 `pip install <一个小包>`（或 20 秒以上的 Python 脚本），执行期间点菜单/切会话；
     期望界面不冻结、进度与输出仍会滚动出现；
  3. 长时间使用（≥10 分钟，多个会话 + 插件）观察是否还有"规律性 8 秒卡一下"。

### 2.6 平板首次启动左侧栏缺失

- **修复的现象**：划掉应用后重新打开，左侧栏不显示、主界面居中；点右上角按钮后才恢复。
- **怎么验**：从多任务划掉 DSHM → 重新打开 → **左侧栏应直接出现**（不需要点任何按钮）；
  反复 3 次。若仍缺失，请记录设备型号/系统版本/时间点。

### 2.7 工具链自检文案（git 状态）

- **变化**：手持档（手机/平板）不再把"git 在本档不可用"显示为失败，改为显示"本档跳过"；
  避免自检面板/日志里出现误导性的红色 FAIL。
- **怎么验**：设置里跑一次工具链/运行时自检，`git` 一项显示"跳过（本档不支持）"，而不是失败。

### 2.8 稳定性（闪退排查）

- 针对内测崩溃上报里的 `SIGSYS 425`（一类系统调用被系统安全策略拦截导致的闪退）做了**取证与守卫**：
  已确认**当前侧载包的随包组件里不存在该调用**；若测试中仍遇到闪退，请按第 4 节提供时间点，
  研发侧会按设备抓崩溃日志继续定位。

## 3. 建议的 10 分钟冒烟清单

| # | 场景 | 期望 |
|---|---|---|
| 1 | 新建会话 → 发一句话 → 收到回复 | 正常，无卡顿 |
| 2 | 麦克风听写 20 秒 | 文本落输入框 |
| 3 | 打开/收起左侧栏、打开右侧栏（文件/终端） | 不重叠、返回手势逐层退出 |
| 4 | 插件市场安装一个插件 | 安装期间界面可点；安装成功后可启用 |
| 5 | Agent 执行 `pip install requests`（或长脚本） | 执行期间界面不冻结 |
| 6 | 切后台 → 回前台 | 会话与输入不丢 |
| 7 | 2in1：自由窗口缩放、最大化切换 | 四边可缩放、侧栏入口在 |
| 8 | 分屏/旋屏（平板） | 内容不空白、不偏移 |
| 9 | 深浅色切换 | 顶栏/侧栏/输入区配色正常 |
| 10 | 划掉重开 ×3 | 首启侧栏正常出现 |

## 4. 反馈要求（重要）

每条问题请附：

1. **设备型号 + 系统版本 + 设备形态**（手机 / 平板 / 2in1；是否电脑模式或分屏）；
2. **复现步骤**（从哪进入、点了什么、等了多久）；
3. **时间点**（精确到分钟）+ 是否可稳定复现；
4. 截图 / 录屏（卡顿类请录屏，能看出"多久没响应"）；
5. 若应用闪退/被系统杀掉：记录大概时间，研发侧按时间点取崩溃日志。

> 日志由研发侧在设备上抓（`dshm-host.log` / `node-output.log` / `diag-*`），测试组只需要给
> **时间点 + 步骤 + 设备**，不必自行导出。

## 5. 已知限制（不是本版引入）

- 手机端本轮未做专项验证（改动以 PC / 平板为主）。
- 部分平板窗口不提供系统标题栏三键（系统能力限制，非应用缺陷）。
- 账号 / 模型需已登录并配置好凭据，否则 AI 相关功能会提示未配置。
- 侧载包与 AGC 邀测包是两个包名，**不能互相覆盖安装**；测试侧载包时请勿卸载 AGC 包（避免误清数据）。

## 6. 2026-10-19 晚追加：内存风暴修复（MatePad Edge 冒烟后）

**问题**：MatePad Edge 上应用启动约 78 秒触发系统 PSI，随后 97 条杀进程/换页记录，设备重启。

**本轮改动（下一版侧载包生效）**：
1. Web 组件改为**单渲染进程**（少一个渲染子进程常驻）；
2. 接系统内存压力回调，压力升高时主动释放 Web 内核缓存；
3. Host 增加内存看门狗（10 秒采样自身/系统可用内存，落 `diag-mem`）；
4. **VM 后台预热默认关闭**（不再在启动 60 秒后偷偷拉虚拟机；真正使用终端时按需启动，仅首条命令慢约 12 秒）。

**下一轮请重点复测**：启动后保持前台 3 分钟不操作 → 应无系统 PSI/卡死/闪退；
再依次建会话、切后台、划掉重开；如仍异常，请提供时间点 + 录屏（研发按时间点取 `diag-mem`）。
