Under the hood

官方没有鸿蒙端，
那就把运行本体搬过来

这是一次平台移植：把面向桌面 Electron 的运行时，搬到 OpenHarmony arm64 上自足运行。不 fork、不魔改上游，差异只通过 dsh 自己的组合面表达。

  • 端侧自足运行 — HAP 内置 Node 运行时与 dsh 核心树，Host 跑在应用进程内，只监听回环地址。
  • 构建期自签名 — 原生二进制随包分发并自签名，进入应用签名域后才能执行。
  • jitless / 无 WASM — 不申请 JIT，通过 fetch 垫片与 undici 模块名钩子补齐，不改上游源码。
  • 核心可切换可回滚 — 核心树以归档分发，版本仓库激活事务切换，失败自动回滚。
  • 界面不重写 — 官方 Web 前端内容不变，ArkUI 只做平台宿主，官方主题更新无需重做界面。

│  核心版本仓库（多版本并存 / 切换 / 回滚） │
└───────────────────────────────────────────┘
