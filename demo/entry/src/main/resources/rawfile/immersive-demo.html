沉浸光感·网页菜单演示

长按或右键下方五类对象，应用侧接管弹出原生玻璃语境菜单（THIN 材质、锚定触点）。菜单项空集时回退 ArkWeb 系统默认菜单。

1. 链接（IANA 保留示例域）

example.com 示例链接

菜单应出「打开链接 / 复制链接」；点「打开链接」拉起系统浏览器。

2. 图片（内嵌 data URI，无外部资源）

菜单应出「复制图片」；「保存图片」按 API 存在性出现（API>=24）。

3. 可编辑输入框

菜单按可编辑位掩码出「剪切 / 复制 / 粘贴 / 全选」子集。

4. 可选中文本段

这是一段可以选择的文字。长按选中部分文字后松开，菜单应出「复制 / 全选」。语境菜单项由 ArkWeb 的选区状态（getSelectionText / getEditStateFlags）驱动生成。

5. 空白区（菜单项空集，回退系统菜单）

长按此处不带任何语境（非链接、非图片、不可编辑、无选区），应用侧回退 return false，由 ArkWeb 弹系统默认菜单。
